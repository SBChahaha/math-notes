01线性表的定义与基本操作概念

线性表：由 $n$（$n\ge0$）个相同数据类型的数据元素构成的有限序列，记 $$L=(a_1,\ a_2,\ \dots,\ a_n)$$ · $n=0$ 时为空表；$a_1$ 是唯一「第一个」元素（表头），$a_n$ 是唯一「最后一个」（表尾）；
· 除首元素外每个元素有且仅有一个直接前驱，除尾元素外有且仅有一个直接后继；
· 元素的位序从 $1$ 开始计（$a_i$ 是第 $i$ 个元素）；
· 线性表是逻辑结构，其实现（顺序/链式）属于存储结构层面。
九个基本操作（王道命名，必记）：
① InitList(&L)——初始化，构造空表；
② DestroyList(&L)——销毁，释放内存；
③ ListInsert(&L, i, e)——在第 $i$ 个位置插入元素 $e$；
④ ListDelete(&L, i, &e)——删除第 $i$ 个元素，用 $e$ 返回其值；
⑤ LocateElem(L, e)——按值查找，返回第一个值等于 $e$ 的位序（找不到返回 0）；
⑥ GetElem(L, i)——按位查找，返回第 $i$ 个元素；
⑦ Length(L)——求表长；
⑧ PrintList(L)——按序输出；
⑨ Empty(L)——判空。
三个符号约定：「&L」表示引用型参数（会修改表本身，如插入删除）；「&e」是把结果带回给调用者；只有查找类不改变表。考试写伪代码时这些符号要规范使用。

02顺序表顺序存储

定义：用一组地址连续的存储单元依次存储线性表的元素——逻辑上相邻的元素物理上也相邻。
两大特征：① 随机访问：第 $i$ 个元素地址 $=\text{LOC}(a_1)+(i-1)\times\text{sizeof}(E)$，按位查找 $O(1)$；② 插入/删除需要移动元素。
类型定义（静态分配）： 
#define MaxSize 50              // 最大长度
typedef struct {
    ElemType data[MaxSize];     // 顺序存储的元素
    int length;                 // 当前长度
} SqList;                       // 顺序表类型

/* 动态分配版本 */
typedef struct {
    ElemType *data;             // 动态数组指针
    int length, capacity;       // 长度与容量
} SeqList;
关键：位序 $i$ 对应数组下标 $i-1$——代码里永远写 data[i-1]。
插入操作（平均移动 $n/2$）在位置 $i$（$1\le i\le n+1$）插入：把第 $i$ 到 $n$ 个元素从后往前依次后移一位，再写入、长度 +1。
平均移动次数推导：插入位置有 $n+1$ 种等可能，插到第 $i$ 位需移动 $n-i+1$ 个元素： $$\text{平均}=\frac1{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac1{n+1}\cdot\frac{n(n+1)}2=\frac n2$$
删除操作（平均移动 $(n-1)/2$）删除位置 $i$（$1\le i\le n$）：把第 $i+1$ 到 $n$ 个元素从前往后依次前移一位，长度 −1。
平均移动推导：删除位置有 $n$ 种等可能，删第 $i$ 位需移动 $n-i$ 个： $$\text{平均}=\frac1n\sum_{i=1}^{n}(n-i)=\frac1n\cdot\frac{n(n-1)}2=\frac{n-1}2$$
例（插入的完整伪代码）. 
bool ListInsert(SqList &L, int i, ElemType e) {
    if (i < 1 || i > L.length + 1) return false;  // 位序非法
    if (L.length == MaxSize) return false;        // 表满
    for (int j = L.length; j >= i; j--)           // 从后往前移
        L.data[j] = L.data[j-1];                  // 空出第 i 位（下标 i-1）
    L.data[i-1] = e;
    L.length++;
    return true;
}
① 合法性：插入允许到表尾之后（$i=n+1$）⇒ 上界是 $length+1$；② 循环从 $j=n$ 递减到 $i$，共移动 $n-i+1$ 个；③ 时间 $O(n)$（移动）+ $O(1)$（其余）⇒ 总 $O(n)$ ✓。
例（按位查找与按值查找）. 按位查找：return L.data[i-1]; ⇒ $O(1)$（随机访问的威力）；
按值查找：从 $a_1$ 起逐个比较，等概率假设下平均比较 $\dfrac{n+1}2$ 次 ⇒ $O(n)$。
复杂度口诀：顺序表「查位 O(1)、查值 O(n)、插删 O(n)」。
顺序表特点小结：① 支持随机访问；② 存储密度高（只存数据、无指针开销）；③ 需预分配连续空间（可能溢出或浪费）；④ 插入删除平均移动一半元素。

03单链表链式存储核心

定义：每个结点含「数据域 + 指针域」，指针指向下一个结点；结点在内存中不必连续。
· 头指针 L：指向链表的第一个结点（有头结点时指向头结点）；
· 头结点：在第一个数据结点之前附加的「虚」结点（数据域可放表长等信息）——统一空表与非空表的处理、统一首位置插入删除。
graph LR
  L["头结点（头指针 L）"] --> A["a₁ 数据+next"] --> B["a₂ 数据+next"] --> C["a₃ 数据+next"] --> N["NULL"]
类型定义： 
typedef struct LNode {      // 单链表结点
    ElemType data;          // 数据域
    struct LNode *next;     // 指针域：指向后继
} LNode, *LinkList;         // LinkList 为指向结点的指针类型
关键习惯：「结点指针 p」指 LNode *p；访问 p 的域写 p->data、p->next；合法指针才可解引用（空指针解引用是 408 最爱设的坑）。
建立单链表——头插法（结果逆序）： 
LinkList List_HeadInsert(LinkList &L) {
    L = (LNode *) malloc(sizeof(LNode));  // 创建头结点
    L->next = NULL;
    int x;
    while (scanf("%d", &x) != EOF) {      // 逐个读入
        LNode *s = (LNode *) malloc(sizeof(LNode));
        s->data = x;
        s->next = L->next;                // 新结点接在头结点之后
        L->next = s;
    }
    return L;
}
① 每个结点插入均为 $O(1)$；总时间 $O(n)$；② 数据顺序与输入相反——「输入 1,2,3，得到 3,2,1」是惯性考点 ✓。
建立单链表——尾插法（结果同序）： 
LinkList List_TailInsert(LinkList &L) {
    L = (LNode *) malloc(sizeof(LNode));
    L->next = NULL;
    LNode *r = L;                         // r 始终指向表尾
    int x;
    while (scanf("%d", &x) != EOF) {
        LNode *s = (LNode *) malloc(sizeof(LNode));
        s->data = x;
        s->next = NULL;
        r->next = s;  r = s;              // 链接并更新尾指针
    }
    return L;
}
对照记忆：头插不用尾指针但逆序；尾插需要尾指针 r 但保序——两种都是 $O(n)$ 总时间。
插入（在结点 p 之后插入 s）： 
s->next = p->next;    // ① 先让新结点接住后继
p->next = s;          // ② 再断开、指到新结点
/* 顺序颠倒（先 p->next=s 再 s->next=…）会丢失原后继！ */
前插技巧（在 p 之前插入 s，但只给了 p）：把 s 插到 p 之后，再交换 p 与 s 的数据域——仍是 $O(1)$（经典脑筋题）。
删除（删除 p 的后继 q）： 
q = p->next;          // q 为待删结点
p->next = q->next;    // 摘链
free(q);              // 必须释放！
查找（均 $O(n)$）：按位查找：从头结点出发走 $i$ 步（不是随机访问）；按值查找：逐个比较数据域。附带结论：求表长也要走一遍 ⇒ $O(n)$（这是与顺序表 $O(1)$ 的区别之一，但若头结点数据域存了长度则可 $O(1)$——考查对头结点用途的理解）。

04双链表、循环链表与静态链表三种变体

（1）双链表（prior + next）

typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;   // 前驱 + 后继
} DNode, *DLinkList;
插入（在 p 之后插入 s，四条指针，注意顺序）： 
s->next = p->next;              // ① s 接后
if (p->next != NULL)
    p->next->prior = s;         // ② 后结点的前驱指向 s
s->prior = p;                   // ③ s 的前驱指向 p
p->next = s;                    // ④ p 的后继指向 s
删除（删除 p 的后继 q）： 
q = p->next;
if (q == NULL) return false;
p->next = q->next;              // p 跳过 q
if (q->next != NULL)
    q->next->prior = p;         // 补上后结点的前驱
free(q);
要点：改指针时先保住「邻居」，别先断链；判断边界（表头/表尾）防空指针。

（2）循环链表

· 单循环链表：表尾结点的 next 指回头结点——从任意结点出发都能遍历全表；
· 判空：带头结点时 L->next == L；判表尾：p->next == L；
· 双循环链表：头结点的 prior 指向表尾（首尾互指）。
经典操作（带尾指针 rear 的循环单链表）：合并两个循环单链表 A、B：只需三步改指针—— 
p = A_rear->next;           // 记住 A 的头结点
A_rear->next = B_rear->next->next;  // A 尾部接 B 的第一个数据结点
B_rear->next = p;           // B 尾部指回 A 的头结点
A_rear = B_rear;            // 新表尾更新
把原本要「两表各扫一遍」的操作压缩到 $O(1)$（前提：A、B 均非空）——带尾指针的循环链表的威力所在。

（3）静态链表（数组模拟）

#define MaxSize 50
typedef struct {
    ElemType data;       // 数据
    int next;            // 游标：下一元素的下标（−1 表示结束）
} SLinkList[MaxSize];
· 用数组模拟链式结构，next 存数组下标而不是真实地址；
· 适用于不支持指针的语言，或需要固定容量、便于序列化的场景；
· 位序与下标不再相等——要沿游标跳着找（不能随机访问）；
· next == -1 表示链表结束；约定下标 0 为头结点时，空表 ⇔ S[0].next == -1。插入删除同样是「改游标」。

05顺序表 vs 链表（必考对比）高频

维度顺序表链表
存取方式随机访问：按位查找 $O(1)$顺序访问：按位查找 $O(n)$
逻辑与物理逻辑相邻 ⇒ 物理相邻物理位置任意（指针链）
插入/删除平均移动一半元素 ⇒ $O(n)$已定位后改指针 ⇒ $O(1)$
按值查找$O(n)$（平均 $\frac{n+1}2$ 次比较）$O(n)$
空间分配预分配连续空间：可能溢出或闲置按需分配：无溢出问题，但指针占额外空间
存储密度高（≈1）小于 1（含指针域）
适用场景表长稳定、频繁按位查找、少插删频繁插删、表长动态变化大
判断题高频辨析：① 「链表按位查找 O(1)」错（那是顺序表）；② 「顺序表插入总需移动元素」——插到表尾时移动 0 个，但最坏/平均仍是 $O(n)$；③ 「链表能随机访问」错；④ 「顺序表存储密度一定为 1」——若是记录结构，两者都含数据项，比较的是「是否额外带指针」；一般题面按「存储密度高」记顺序表优势；⑤ 「链表插入一定 O(1)」——只有已经拿到插入位置指针时才 O(1)，若需先按位查找则总体 $O(n)$。
一句话判别：题目要「频繁按位查找/求第 k 个」⇒ 倾向顺序表；题目要「频繁插入删除/长度难预估」⇒ 倾向链表。

06典型例题四道经典操作

例 1（顺序表：删除最小值元素，空位用表尾元素填补）. 
bool Del_Min(SqList &L, ElemType &value) {
    if (L.length == 0) return false;        // 空表
    value = L.data[0];  int pos = 0;        // 记最小值与位置
    for (int i = 1; i < L.length; i++)      // 找最小值
        if (L.data[i] < value) { value = L.data[i]; pos = i; }
    L.data[pos] = L.data[L.length - 1];     // 表尾元素填坑
    L.length--;                             // 长度减一
    return true;
}
① 扫描一遍找最小值与位置：$O(n)$；② 填补+缩短：$O(1)$；③ 总时间 $O(n)$、辅助空间 $O(1)$（原地）✓。
易错：若先 L.length-- 再取表尾，取到的就不是原表尾元素（$n=1$ 时还会越界）；填坑用表尾而不是前移（前移会多 $O(n)$）。
例 2（单链表就地逆置：头插法）. 
void Reverse(LinkList &L) {
    LNode *p = L->next, *q;         // p 从第一个数据结点开始
    L->next = NULL;                 // 头结点与链表断开（当作新空表）
    while (p != NULL) {
        q = p->next;                // ① 暂存后继，防丢链
        p->next = L->next;          // ② 头插到新表
        L->next = p;
        p = q;                      // ③ 继续处理原表
    }
}
① 每个结点做 $O(1)$ 次指针操作，共 $n$ 个 ⇒ 时间 $O(n)$；② 只用 p、q 两个辅助指针 ⇒ 空间 $O(1)$（原地逆置）✓。
原理：头插法天然产生逆序——把原表结点逐个「头插」到新表即可；第一步必须暂存 q。
例 3（快慢指针：求中间结点）. 
LNode *Find_Mid(LinkList L) {
    LNode *slow = L, *fast = L;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;            // 慢：一步
        fast = fast->next->next;      // 快：两步
    }
    return slow;                      // 中间结点
}
① 正确性：快指针速度是慢指针 2 倍，快指针到表尾时慢指针恰好走到中点；② 循环条件两个条件缺一不可（防 fast 或 fast->next 为空时解引用）；③ 时间 $O(n)$、空间 $O(1)$。长度偶数时 slow 落在前半最后一个（fast->next==NULL 退出）；空表时返回头结点（调用方需判空）✓。
同族技巧：「找倒数第 k 个」用双指针拉开 k 步同步走（一次遍历 $O(n)$）。
例 4（合并两个有序链表，尾插保序）. 
void MergeList(LinkList &A, LinkList &B) {
    LNode *pa = A->next, *pb = B->next, *r = A;   // r 为新表尾
    A->next = NULL;
    while (pa && pb) {                            // 谁小接谁
        if (pa->data <= pb->data) { r->next = pa; pa = pa->next; }
        else                      { r->next = pb; pb = pb->next; }
        r = r->next;
    }
    r->next = (pa != NULL) ? pa : pb;             // 接上剩余段
    free(B);                                      // 释放 B 的头结点
}
① 每个结点至多被「接」一次 ⇒ 时间 $O(n+m)$（$n,m$ 为两表长）；② 直接复用原结点、只改指针 ⇒ 空间 $O(1)$ ✓；③ 结束时剩余段整体挂上即可（有序性保证）——408 大题常考的归并骨架。

07决策流程与易错点

线性表操作题
├─ 顺序表
│   ├─ 插入 i∈[1, n+1]：从后往前移（for j=n downto i）
│   ├─ 删除 i∈[1, n]：从前往后移（for j=i to n−1）
│   ├─ 按位 O(1)、按值 O(n)
│   └─ 平均移动：插入 n/2、删除 (n−1)/2
├─ 单链表
│   ├─ 插入：先接后断（s->next=p->next; p->next=s）
│   ├─ 删除：暂存后继 → 摘链 → free
│   ├─ 建表：头插逆序 / 尾插保序（尾指针 r）
│   └─ 查找与求长：O(n) 顺序访问
├─ 双链表：插入四指针（先连新的、再改旧的）；删除补邻居 prior
├─ 循环链表：next==头 判空/表尾；带尾指针合并 O(1)
├─ 静态链表：沿游标跳转（下标 ≠ 位序）
└─ 收尾检查：空表/边界 → 内存释放 → 复杂度与是否原地

易错点清单

  1. 位序从 1 开始：代码里第 $i$ 个元素是 data[i-1]——「第几位」与「下标」差 1。
  2. 插入范围 $1\sim n+1$、删除范围 $1\sim n$：插入可以插到表尾之后；边界检查要在移动之前。
  3. 顺序表移动方向：插入从后往前（防覆盖）、删除从前往后——方向反了数据就被冲掉。
  4. 链表插入「先接后断」：必须先让 s 接住原后继，再改 p 的指针；否则后继丢失。
  5. 头指针 vs 头结点：头指针是「指向第一个结点的指针」（永远存在），头结点是「附加的虚结点」（可无）；有头结点时空表是 L->next==NULL。
  6. 快慢指针循环条件：fast != NULL && fast->next != NULL 两个都不能少（缺一个就可能解引用空指针）。
  7. 删除时先暂存再 free：q=p->next 之后才可操作；free 之后不能再用 q->next——顺序错了程序崩塌。
  8. 双链表插入的顺序：典型的四步要先接好新结点的两条链，再让邻居认它；任一步都别裸断链。
  9. 「链表插入 O(1)」有前提：已经拿到插入位置的指针；若需要先按位查找，总体仍 $O(n)$。
  10. 循环链表的终止条件：不是 NULL 而是「回到头」（p==L 或 p->next==L）——沿用 NULL 判断会死循环。

08公式速查表

操作顺序表链表
按位查找$O(1)$（随机访问）$O(n)$
按值查找$O(n)$（平均 $\frac{n+1}2$ 次）$O(n)$
插入$O(n)$，平均移动 $\frac n2$已定位 $O(1)$；含查找 $O(n)$
删除$O(n)$，平均移动 $\frac{n-1}2$已定位 $O(1)$；含查找 $O(n)$
求表长$O(1)$（length 域）$O(n)$（遍历；头结点存长度可 $O(1)$）
建表逐个填入 $O(n)$头插 $O(n)$（逆序）；尾插 $O(n)$（保序）
链表三板斧（默写级）： 
/* 插入：p 之后插 s */        /* 删除：删 p 的后继 */        /* 双链表：p 之后插 s */
s->next = p->next;           q = p->next;                   s->next = p->next;
p->next = s;                 p->next = q->next;             if (p->next) p->next->prior = s;
                             free(q);                       s->prior = p;  p->next = s;
一句话总纲：顺序表「存得紧凑、查位飞快，插删全在搬家」；链表「查得慢、插删快，全靠指针链」。所有操作题先问三件事：定位了吗？改了几条指针？释放了吗？
