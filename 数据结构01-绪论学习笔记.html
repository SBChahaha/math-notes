01数据结构的基本概念概念

四个层层包含的术语：
① 数据：信息的载体，是描述客观事物属性的数、字符及所有能输入到计算机中并被计算机程序识别和处理的符号的集合。
② 数据元素：数据的基本单位，通常作为一个整体进行考虑和处理（也称元素、结点、记录）。
③ 数据项：构成数据元素的不可分割的最小单位（如字段）；可分为原子项与组合项。
④ 数据对象：具有相同性质的数据元素的集合，是数据的一个子集。

例（学生表）. 全体学生信息构成一个数据对象；其中一行「(2024001, 张三, 男, 18)」是一个数据元素（一条记录）；「学号」「姓名」等每个字段是一个数据项（原子项）；若某字段「出生日期」再拆成「年/月/日」，则它是组合项。
再练一例：全年棋谱是数据，其中「一局棋」是数据元素，「某一步走法（如马二进三）」是数据项——数据项是不能再拆的最小单位 ✓。
数据结构：相互之间存在一种或多种特定关系的数据元素的集合。它包含三个要素：
① 逻辑结构——数据元素之间的逻辑关系（面向问题、独立于计算机）；
② 存储结构——数据结构在计算机中的表示（面向实现、依赖计算机）；
③ 数据的运算——施加在数据上的操作（增删改查等），定义针对逻辑结构而言，实现要落到存储结构上。

02逻辑结构与存储结构三要素核心

（1）逻辑结构：四种基本类型

① 集合：元素之间除了「同属一个集合」外无其他关系；
② 线性结构：一对一（线性表、栈、队列、串）；
③ 树形结构：一对多（树、二叉树）；
④ 图状结构（网状）：多对多（图）。

（2）存储结构：四种实现方式

① 顺序存储：逻辑相邻的元素物理位置也相邻（数组）——可随机访问，插入删除要移动元素；
② 链式存储：借助指针表示逻辑关系（链表）——插入删除方便，不能随机访问；
③ 索引存储：建立附加的索引表（关键字 → 地址）——检索快，索引表占空间、增删要维护；
④ 散列存储（哈希）：由关键字直接算出地址——理想情况下检索 O(1)，可能冲突。
存储方式核心思想优点缺点
顺序存储地址连续、逻辑相邻即物理相邻随机访问 O(1)插入/删除需移动元素；需连续空间
链式存储指针链起离散结点插入/删除只改指针不能随机访问；指针占额外空间
索引存储索引表 + 数据表按关键字检索快索引表开销；维护成本
散列存储哈希函数直接定地址平均检索最快存在冲突；设计依赖哈希函数
三个必记辨析：
① 逻辑结构与存储结构是两个层面：逻辑结构独立于计算机，存储结构是其在计算机中的表示——同一种逻辑结构可以有不同的存储结构（线性表既可顺序表也可链表）；
② 顺序存储一定是随机存取的（地址连续 ⇒ 可算出任意元素位置）；链式存储不是；
③ 顺序存储是「存储结构」概念，而「顺序表」是「线性表采用顺序存储」的实例化名称——术语层级不要搞混。

03算法的基本概念概念

算法：对特定问题求解步骤的描述，是指令的有限序列。算法与程序不同——程序可以不满足有穷性（如操作系统），算法必须满足。
算法的五大特性（必背）：
① 有穷性：算法必须在执行有穷步之后结束，且每一步都在有穷时间内完成；
② 确定性：每条指令含义确切、无歧义；相同输入只能得到相同输出；
③ 可行性：算法中的操作都可以通过已实现的基本运算执行有限次来实现；
④ 输入：零个或多个输入；
⑤ 输出：一个或多个输出（没有输出的算法没有意义）。
「好算法」的四个目标：① 正确性（能正确解决问题）；② 可读性（便于理解交流）；③ 健壮性（对非法输入能恰当反应）；④ 高效率与低存储需求（时间、空间复杂度低）。
例（判断是否为算法）.
① 「输出所有自然数」：要求永无止境地输出 ⇒ 不满足有穷性，不是算法；
② 「令 x 等于其绝对值的平方根」：结果有歧义 ⇒ 不满足确定性，不是算法；
③ 从 a、b 两数中取较大者输出：有输入 2 个、输出 1 个、有限步 ⇒ 是算法 ✓；
记忆链：有穷、确定、可行 + 入出。「有穷性」是算法与程序的第一分界。

04时间复杂度全科核心技能

定义（大 O）：设 $T(n)$ 为算法基本操作执行次数，若存在常数 $C>0$ 与 $n_0$，使当 $n\ge n_0$ 时恒有 $$0\le T(n)\le C\cdot f(n)$$ 则记 $T(n)=O(f(n))$——大 O 表示的是渐近上界（数量级）。
分析三步法：
① 选「基本操作」（通常是最深层循环内的那条语句）；
② 数出它的执行次数，写成 $n$ 的表达式（数列求和 / 找规律）；
③ 只保留最高阶项、去掉系数与常数（如 $\frac{n(n+1)}{2}\Rightarrow O(n^2)$）。
例 1（单层循环）. 
for (i = 1; i <= n; i++)
    x++;        // 基本操作
① 基本操作 x++ 在 i=1…n 各执行一次 ⇒ 次数 $=n$；② 结论：$T(n)=O(n)$ ✓。
例 2（双层独立循环）. 
for (i = 1; i <= n; i++)      // n 轮
    for (j = 1; j <= m; j++)  // 每轮 m 次
        x++;
总次数 $=n\times m$ ⇒ $O(nm)$；若 $m=n$ 则 $O(n^2)$ ✓（独立嵌套用乘法）。
例 3（内层依赖外层）. 
for (i = 1; i <= n; i++)
    for (j = 1; j <= i; j++)
        x++;
① 内层执行次数随 i 变化：$1+2+\cdots+n$；② 求和 $=\dfrac{n(n+1)}2=\dfrac{n^2}2+\dfrac n2$；③ 取最高阶 ⇒ $O(n^2)$ ✓（依赖嵌套用求和）。
例 4（倍增循环）. 
i = 1;
while (i <= n)
    i = i * 2;   // 基本操作：每次翻倍
① 设执行 $k$ 次后 $i=2^k$，循环终止条件 $2^k>n$ ⇒ 最小整数 $k=\lfloor\log_2 n\rfloor+1$；② 次数 $=\lfloor\log_2 n\rfloor+1$ ⇒ $T(n)=O(\log n)$ ✓（对数的底数在 O 记号中不写）。
对照：若改为 i = i + 3，则次数约 $n/3$ ⇒ $O(n)$——「乘除走对数、加减走线性」。
常见阶的增速排序（必背） $$O(1)\lt O(\log n)\lt O(n)\lt O(n\log n)\lt O(n^2)\lt O(n^3)\lt O(2^n)\lt O(n!)\lt O(n^n)$$
最坏 / 平均 / 最好时间复杂度：同一算法对规模为 $n$ 的不同输入，执行次数可能不同。以顺序查找（在长 $n$ 的表中找 $x$）为例：
· 最好：第一个就是，$1$ 次 ⇒ $O(1)$；
· 最坏：找到最后一个或找不到，$n$ 次 ⇒ $O(n)$；
· 平均：每个位置被查概率 $1/n$，期望次数 $=\sum\limits_{i=1}^n i\cdot\dfrac1n=\dfrac{n+1}2$ ⇒ $O(n)$。
408 惯例：不特别说明时，时间复杂度指最坏情况。

05空间复杂度另一把尺子

定义：算法所需存储空间 = 输入数据所占空间 + 程序本身所占空间 + 辅助变量所占空间。讨论空间复杂度时，通常只分析辅助空间（额外需要的临时变量/数组/栈）随 $n$ 的渐近变化，记 $S(n)=O(g(n))$。
若辅助空间与 $n$ 无关（常数个临时变量），称算法原地工作（in-place），$S(n)=O(1)$。
例 1（原地逆置数组）. 
void reverse(int a[], int n) {
    int i = 0, j = n - 1, t;
    while (i < j) { t = a[i]; a[i] = a[j]; a[j] = t; i++; j--; }
}
只用了 $i,j,t$ 三个临时变量 ⇒ 辅助空间 $O(1)$（原地工作）✓；时间上每个元素交换一次 ⇒ $O(n)$。
例 2（合并两个有序数组）. 要把长度 $n$ 与 $m$ 的两个有序表合并到新表：必须开 $n+m$ 的新数组 ⇒ 辅助空间 $O(n+m)$；若只在一个表上借 $O(\min(n,m))$ 缓冲合并，仍是线性空间（时间换空间）；严格意义上的原地合并（$O(1)$ 辅助）需要旋转类算法、时间代价更高。
结论：「能不能原地」是空间分析的第一问——只有常数个临时变量才算 $O(1)$。
例 3（递归的空间 = 栈深度）. 计算 $n!$ 的递归： 
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
每层递归需要一个栈帧（参数 n、返回地址等），最深嵌套 $n$ 层 ⇒ 空间复杂度 $O(n)$；时间上每层一次乘法 ⇒ $O(n)$。
对照（迭代版）：循环累乘只用一个变量 ⇒ 时间 $O(n)$、空间 $O(1)$ ✓。
例 4（斐波那契：递归的代价）.
· 递归版 fib(n)=fib(n-1)+fib(n-2)：时间以 $O(2^n)$ 级数增长（子问题重复计算），栈深 $n$ ⇒ 空间 $O(n)$；
· 迭代版：两个变量滚动 ⇒ 时间 $O(n)$、空间 $O(1)$；
结论：同一问题的不同算法，时间与空间可能差出若干个数量级——这正是复杂度分析的意义 ✓。

06典型例题数次数四练

例 1（嵌套 + 倍增组合）. 分析下列代码的时间复杂度： 
for (i = 1; i <= n; i++)        // 外层 n 轮
    for (j = 1; j <= n; j = j * 2)  // 内层倍增
        x++;
① 外层 $n$ 轮；② 内层 $j$ 取 $1,2,4,\dots,2^k$，由 $2^k\le n$ 得执行 $\log_2 n+1$ 次；③ 两层相互独立 ⇒ 乘法：$n(\log_2 n+1)$；④ 结论 $O(n\log n)$ ✓（「独立」+「倍增」= 乘法 + 对数）。
例 2（三层循环的累加）. 
x = 0;
for (i = 1; i <= n; i++)
    for (j = 1; j <= n; j++)
        for (k = 1; k <= j; k++)
            x++;
① 固定 $i$：内两层次数 $=\sum\limits_{j=1}^{n}j=\dfrac{n(n+1)}2$；② 外层 $n$ 轮 ⇒ 总数 $=n\cdot\dfrac{n(n+1)}2=\dfrac{n^3}2+\dfrac{n^2}2$；③ 结论 $O(n^3)$ ✓（逐层往内求和，再乘外层）。
例 3（while 循环跟踪法）. 
i = 3;
while (i <= n)
    i = i * 3;
① 设执行 $k$ 次后 $i=3^{k+1}$；② 条件 $3^{k+1}>n$ ⇒ $k>\log_3 n-1$；③ 次数 $=\lfloor\log_3 n\rfloor$ 级别（约 $\log_3 n$）⇒ $O(\log n)$ ✓。
对照：i = i + 3 ⇒ 次数 $(n-3)/3$ 级别 ⇒ $O(n)$——乘法走对数、加法走线性（本节最常考的区分）。
例 4（递归的时间递推）. 计算 $T(n)=T(n-1)+n$（$T(1)=1$）的阶。
① 逐层展开：$T(n)=T(n-1)+n=T(n-2)+(n-1)+n=\cdots=T(1)+2+3+\cdots+n$；
② 求和：$T(n)=1+\dfrac{(2+n)(n-1)}2=\dfrac{n^2+n-2}2+1$；
③ 取最高阶：$O(n^2)$ ✓（递归先写递推式，再逐层展开成求和）。
对照速记：$T(n)=T(n-1)+c\Rightarrow O(n)$；$T(n)=T(n-1)+n\Rightarrow O(n^2)$；$T(n)=2T(n-1)+c\Rightarrow O(2^n)$；$T(n)=T(n/2)+c\Rightarrow O(\log n)$。

07决策流程与易错点

graph TD
  Q["复杂度分析题"] --> C1["循环型"]
  C1 --> C1a["单层：i++ → n；i+=c → n/c；i*=k → log_k n"]
  C1 --> C1b["嵌套独立：相乘"]
  C1 --> C1c["嵌套依赖：逐层求和 Σ"]
  Q --> C2["while 型：跟踪变量（倍增 → 对数；累加 → 线性）"]
  Q --> C3["递归型：写递推式 → 展开成求和"]
  Q --> C4["空间型：只算辅助空间（递归 = 最大深度）"]
  Q --> C5["收尾：取最高阶、去系数；log 不写底数"]

易错点清单

  1. 基本操作选最深层循环内的语句：不是数代码行数。
  2. 依赖嵌套求和、独立嵌套相乘：内层上界含外层变量（如 $j\le i$）必须 $\Sigma$，别直接乘。
  3. log 阶不写底数：$O(\log_2 n)$ 与 $O(\log_3 n)$ 同阶；且 $\log n$ 增长远慢于 $n$。
  4. 空间只算辅助空间：输入数据本身不计；递归的栈空间必须计入。
  5. $O(1)$ 是常数阶：固定执行 100 次的循环仍是 $O(1)$，不是「只执行一次」。
  6. 默认最坏情况：题目不说明时按最坏；平均复杂度要按概率加权（顺序查找 $\frac{n+1}2$）。
  7. 提前退出会降阶：循环里有 break/return 时，次数可能远小于全循环（如查找命中即止）。
  8. 系数与最高阶：大 O 忽略系数，但中间算次数时系数要写对（$\frac{n(n+1)}2$ 别丢成 $n^2/2$ 外的项再求和出错）。
  9. 乘法变变量走对数、加法走线性：$i{*}2$ 与 $i{+}2$ 的循环次数天差地别。
  10. 递归空间 = 最大深度而不是总调用次数：如 fib 递归总调用 $O(2^n)$ 次，但栈深仅 $n$（空间 $O(n)$）。
