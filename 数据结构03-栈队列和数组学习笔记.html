01栈与顺序栈LIFO

栈：只允许在一端（栈顶 top）进行插入和删除的线性表——后进先出（LIFO）。插入称入栈（push），删除称出栈（pop）；另一端称栈底（固定不动）。
数学性质：$n$ 个元素依次入栈，可能的出栈序列共有卡特兰数 $\dfrac{1}{n+1}C_{2n}^{n}$ 种（$n=3$ 时 5 种、$n=4$ 时 14 种）——实际序列是否可达要用栈模拟判断。
graph LR
  B["栈底 a₁
（固定）"] --> C["a₂"] --> D["a₃ 栈顶 top
push / pop 都在此端"]
顺序栈类型定义（王道约定：top 指向栈顶元素）： 
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize];   // 存放栈中元素
    int top;                  // 栈顶指针（下标）
} SqStack;
/* 初始化：S.top = -1  ⇒  空栈判据 top == -1
   栈满判据：top == MaxSize - 1            */
另一种约定：top 指向「栈顶元素的下一个位置」（初始 0）——判据全部随之平移（空 top==0、满 top==MaxSize）。读题代码先确认约定，这是 408 最爱设的细节坑。
入栈 / 出栈（先判越界，再动指针）： 
bool Push(SqStack &S, ElemType x) {
    if (S.top == MaxSize - 1) return false;   // 栈满
    S.data[++S.top] = x;                      // 先加指针，再存
    return true;
}
bool Pop(SqStack &S, ElemType &x) {
    if (S.top == -1) return false;            // 栈空
    x = S.data[S.top--];                      // 先取值，再减指针
    return true;
}
① 入栈是「先 ++ 后存」、出栈是「先取后 --」——顺序记牢；② 两者时间都是 $O(1)$；③ 取栈顶（不出栈）：`x = S.data[S.top];`。
例（出栈序列模拟演示）. 依次入栈 1、2、3、4，判断出栈序列「2, 4, 3, 1」是否可能：
① 入 1、入 2、出 2（栈：1）；② 入 3、入 4、出 4（栈：1, 3）；③ 出 3（栈：1）；④ 出 1 —— 可行 ✓。
方法核心：用「栈内容 + 下一个待入元素」逐步推演；凡是需要「越过栈顶」的输出都不可行——如「3, 1, 2」：出 3 后栈为 (1,2)，栈顶是 2，1 无法先出 ⇒ 不可行 ✓。

02链栈与共享栈两种变体

（1）链栈（头插法即入栈）

typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LiStack;        // 链栈（通常带头结点）
· 栈顶 = 第一个数据结点（`L->next`）；
· 入栈 = 在头结点之后头插；出栈 = 删除第一个数据结点；
· 所有操作 $O(1)$，且不存在栈满（除非内存耗尽）——与顺序栈相比无需预先估计容量。
例（链栈代码）. 
bool Push(LiStack &L, ElemType x) {       // 入栈
    LNode *s = (LNode *) malloc(sizeof(LNode));
    if (s == NULL) return false;          // 内存耗尽
    s->data = x;  s->next = L->next;      // 头插
    L->next = s;
    return true;
}
bool Pop(LiStack &L, ElemType &x) {       // 出栈
    if (L->next == NULL) return false;    // 空栈
    LNode *p = L->next;
    x = p->data;  L->next = p->next;      // 摘链
    free(p);
    return true;
}
与单链表头插/删除首结点完全同构——链栈没有发明新机制，只是「限定操作端」。

（2）共享栈（两端向中间生长）

typedef struct {
    ElemType data[MaxSize];
    int top0;    // 栈 0 的栈顶：从 −1 向上长
    int top1;    // 栈 1 的栈顶：从 MaxSize 向下长
} ShStack;
/* 初始化：top0 = -1, top1 = MaxSize
   栈 0 满进：data[++top0]      栈 1 满进：data[--top1]
   栈空：top0 == -1 / top1 == MaxSize
   共享栈满（核心！）：top0 + 1 == top1        */
· 两个栈共用一段空间、从两端向中间生长——只有当整片空间耗尽（相遇）才算满：空间利用率更高；
· 满条件 $top_0+1==top_1$：不是 $\ge$、不是 $-$，判据写错即丢分。

03循环队列判空判满必考

队列：只允许在一端（队尾 rear）插入、另一端（队头 front）删除的线性表——先进先出（FIFO）。
顺序队列的假溢出：front、rear 只增不减，出队后的空间无法复用——即使数组没满也「看似满了」。解决办法：把数组在逻辑上「掰弯」成环——循环队列（指针移动用取模）。
循环队列示意（MaxSize = 6，牺牲单元法）
 下标:   0     1     2     3     4     5
       [ a ] [ b ] [ c ] [   ] [   ] [   ]
         ↑front                     ↑rear
 入队：Q.rear = (Q.rear + 1) % MaxSize
 出队：Q.front = (Q.front + 1) % MaxSize
 元素数 = (Q.rear − Q.front + MaxSize) % MaxSize
判空判满三方案（必背对比）
方案队空条件队满条件元素个数最大容量
① 牺牲一个单元front == rear(rear+1)%M == front(rear−front+M)%MM−1
② 增设 size 变量size == 0size == MsizeM
③ 增设 tag 标记front==rear 且 tag==0front==rear 且 tag==1按 front/rear 推算M
方案③ 的 tag 含义：每次删除成功后置 tag=0，每次插入成功后置 tag=1——只有 front==rear 时才需要靠 tag 区分「空还是满」。
例（循环队列代码，牺牲单元法）. 
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize];
    int front, rear;              // 队头、队尾（rear 指向队尾元素的下一个位置）
} SqQueue;

void InitQueue(SqQueue &Q) { Q.front = Q.rear = 0; }
bool EnQueue(SqQueue &Q, ElemType x) {
    if ((Q.rear + 1) % MaxSize == Q.front) return false;  // 队满
    Q.data[Q.rear] = x;                                   // 存到 rear 处
    Q.rear = (Q.rear + 1) % MaxSize;                      // 循环后移
    return true;
}
bool DeQueue(SqQueue &Q, ElemType &x) {
    if (Q.front == Q.rear) return false;                  // 队空
    x = Q.data[Q.front];
    Q.front = (Q.front + 1) % MaxSize;                    // 循环后移
    return true;
}
① 初始化 front=rear=0（不设 −1——这是循环队列与顺序栈初始化的区别）；② 所有操作 $O(1)$；③ 「rear 指向队尾元素」还是「队尾的下一个位置」两种约定同样要按题面确认。
数值演练：M=8，初始 front=rear=0；入队 5 个 ⇒ rear=5；出队 2 个 ⇒ front=2；元素数 $=(5-2+8)\%8=3$ ✓。

04链式队列与双端队列变体

（1）链式队列（带头结点）

typedef struct LinkNode {     // 队列结点
    ElemType data;
    struct LinkNode *next;
} LinkNode;
typedef struct {              // 链式队列
    LinkNode *front, *rear;   // 队头指针 + 队尾指针
} LinkQueue;
· 初始（带头结点）：front 与 rear 都指向头结点，队空判据 front == rear；
· 入队 = 尾插后移 rear；出队 = 删除 front 的后继结点；
· 最易错的一步：当出队删掉的是最后一个结点时，必须把 rear 重新指回 front（否则 rear 悬空，下次入队断链）。
例（链队入队 / 出队）. 
void EnQueue(LinkQueue &Q, ElemType x) {
    LinkNode *s = (LinkNode *) malloc(sizeof(LinkNode));
    s->data = x;  s->next = NULL;      // 新结点必为尾
    Q.rear->next = s;                  // 接到队尾
    Q.rear = s;                        // 更新尾指针
}
bool DeQueue(LinkQueue &Q, ElemType &x) {
    if (Q.front == Q.rear) return false;   // 队空
    LinkNode *p = Q.front->next;           // 第一个数据结点
    x = p->data;
    Q.front->next = p->next;               // 摘链
    if (Q.rear == p) Q.rear = Q.front;     // 【关键】删到空时回指头结点
    free(p);
    return true;
}
不带头结点的版本：队空是 `front == NULL`；出队删除的是首结点，若它是最后一个，front 与 rear 都要置 NULL——边界更多、更易错，真题代码多用带头结点版。

（2）双端队列（Deque）

· 双端队列：两端都可以插入、两端都可以删除；
· 输入受限双端队列：只允许一端插入（另一端只能删）；输出受限：只允许一端删除；
· 与栈的关系：栈是「只在一端插删」的极端，属于双端队列的特例——凡栈能产生的输出序列，双端队列都能产生（能力更强）；
· 经典考题：给输入序列 1,2,3,4，问某输出序列能否由「输入受限/输出受限的双端队列」得到——一律用模拟法逐项验证。
队列全家福记忆链：顺序队列（假溢出）→ 循环队列（取模 + 判空判满三方案）→ 链式队列（头结点 + 出空回指）→ 双端队列（两端自由度）。

05栈和队列的应用三大经典

（1）括号匹配（栈的招牌应用）

算法规则：从左到右扫描表达式——
① 遇到左括号：入栈；
② 遇到右括号：若栈空 ⇒ 不匹配（右括号多余）；否则弹出栈顶看是否配对——不配对 ⇒ 失败；
③ 扫描完毕：栈非空 ⇒ 不匹配（左括号多余）；栈空才合法。
例（代码 + 轨迹）. 
bool BracketCheck(char str[], int length) {
    SqStack S;  InitStack(S);
    for (int i = 0; i < length; i++) {
        if (str[i]=='(' || str[i]=='[' || str[i]=='{')
            Push(S, str[i]);                      // 左括号入栈
        else {
            if (StackEmpty(S)) return false;      // 右括号多余
            char top;
            Pop(S, top);
            if (!Match(top, str[i])) return false; // 配对失败
        }
    }
    return StackEmpty(S);                         // 左括号多余则 false
}
轨迹演示（输入「{[()]}」）：「{」进、「[」进、「(」进、「)」与「(」配（弹出）、「]」与「[」配、「}」与「{」配 ⇒ 栈空，合法 ✓。
反例「[(])」：「)」到来时栈顶是「[」⇒ 配对失败 ✗——错的不是数量、是嵌套顺序，这正是必须用栈的原因。

（2）表达式求值：中缀 → 后缀（栈的第二个招牌）

中缀转后缀·手算规则（必背）：从左到右扫描中缀表达式——
① 操作数：直接输出；
② 运算符：与栈顶运算符比较优先级——栈顶 ≥ 当前 且栈顶不是括号时，弹出栈顶输出，再压入当前；否则直接压入；
③ 左括号：直接压栈；
④ 右括号：持续弹出并输出，直到遇到左括号（左括号弹出但不输出）；
⑤ 扫描结束：把栈中剩余运算符全部弹出输出。
优先级：$*、/ > +、-$（同级按左结合处理——上面的「≥ 就弹」正好实现左结合）。
例（完整轨迹表）. 中缀：A + B * (C − D) − E / F
步骤读入动作栈（底→顶）输出
1A操作数输出空A
2+栈空，压栈+A
3B输出+A B
4*高于栈顶 +，压栈+ *A B
5(左括号压栈+ * (A B
6C输出+ * (A B C
7−栈顶是括号，压栈+ * ( −A B C
8D输出+ * ( −A B C D
9)弹出 − 输出；丢弃 (+ *A B C D −
10−弹 *（≥）、弹 +（同级），压 −−A B C D − * +
11E输出−…E
12/高于栈顶 −，压栈− /…E
13F输出− /…E F
14结束弹出 / 与 −空A B C D − * + E F / −
结果：ABCD−*+EF/− ✓。
验算（回代数值）：取 A=1,B=2,C=4,D=1,E=6,F=3：中缀 $=1+2\times3-2=5$；后缀按下面规则求值也应得 5 ✓。
后缀表达式的求值（再一个栈）：从左到右扫描——
① 操作数：入栈；② 运算符：弹出两个操作数，先弹出的是右操作数，计算后压回；③ 扫描完，栈顶即结果。
易错点：减法与除法方向——「右 − 左」写反就全错。例：后缀「34−」⇒ 先弹 4（右）、再弹 3（左），结果 $3-4=-1$。

（3）递归与栈（及队列的用武之地）

· 递归的本质就是栈：每次调用把「返回地址 + 局部变量」压入系统栈，逐层返回时弹栈——最大递归深度 = 栈空间峰值（与第一章复杂度分析的结论呼应）；
· 树形递归（如 fib）调用次数 $O(2^n)$、栈深仅 $n$——「时间爆炸、空间线性」的典型案例；
· 递归转非递归：把系统栈换成显式栈手动模拟（如二叉树非递归遍历）；
· 队列的典型舞台：树的层次遍历、图的广度优先搜索、打印机/任务缓冲——凡「先来先服务」都用队列。

06数组与地址计算计算题基础

数组：由 $n$ 个相同类型数据元素构成的有限序列，是「线性表的推广」——数组一旦建立，维数与各维长度不再改变。数组采用顺序存储，是随机存取结构（按任意下标取元素 $O(1)$）。
一维数组：起始地址 base、每元素占 $L$ 字节（下标从 0）： $$\text{LOC}(a_i)=\text{base}+i\times L\qquad(i\ \text{从}\ 1\ \text{起则}: \text{base}+(i-1)L)$$
二维数组（m 行 × n 列，下标从 0） 行优先（按行存储，C 语言风格）： $$\text{LOC}(a_{ij})=\text{base}+\left[i\times n+j\right]\times L$$ 列优先（按列存储，Fortran 风格）： $$\text{LOC}(a_{ij})=\text{base}+\left[j\times m+i\right]\times L$$ 口诀：行优先乘「列数 $n$」，列优先乘「行数 $m$」——乘错方向是最高频失分点。
若下标从 1 开始：把公式里的 $i$ 换成 $i-1$、$j$ 换成 $j-1$ 即可。
例（地址计算全过程）. 二维数组 $A[0..8][0..9]$（共 9 行 10 列），每个元素占 3 字节，首地址为 100。分别求行优先与列优先下 $A[4][5]$ 的地址。
① 参数：$m=9$（行）、$n=10$（列）、$L=3$、base $=100$；
② 行优先：前面有完整的 4 行（$4\times10=40$ 个）+ 本行前 5 个 ⇒ $$\text{LOC}=100+(4\times10+5)\times3=100+135=235$$ ③ 列优先：前面有完整的 5 列（$5\times9=45$ 个）+ 本列前 4 个 ⇒ $$\text{LOC}=100+(5\times9+4)\times3=100+147=247$$ 验算（数元素个数）：行优先共跳过 $4\times10+5=45$ 个元素；列优先跳过 $5\times9+4=49$ 个——247 比 235 多 $4\times3=12$，恰为 $49-45=4$ 个元素之差 ✓。

07特殊矩阵的压缩存储公式推导

压缩存储思想：① 多个相同元素只分配一个空间；② 零元素不分配；③ 利用矩阵自身的规律（对称、带状、稀疏）减少存储量。压缩后失去随机存取（除按公式映射的规则矩阵外），需要映射公式换算出位置。

（1）对称矩阵（$a_{ij}=a_{ji}$，$n$ 阶）

只存下三角（含主对角线），共 $\dfrac{n(n+1)}2$ 个元素，放入一维数组 $B[0..\frac{n(n+1)}2-1]$（行优先）。
映射公式（$i\ge j$，$i,j$ 从 1 开始，$k$ 为数组下标从 0）： $$k=\frac{i(i-1)}2+(j-1)$$ 推导：第 $i$ 行之前共有 $1+2+\cdots+(i-1)=\dfrac{i(i-1)}2$ 个元素；本行内 $a_{ij}$ 是第 $j$ 个 ⇒ 再加上 $j-1$。
当 $i\lt j$ 时利用对称性 $a_{ij}=a_{ji}$ 换算：把 $i,j$ 互换后套上式。
例（$n=5$ 的对称矩阵）. 求 $a_{43}$ 与 $a_{34}$ 的存储下标。
① $a_{43}$（$4\ge3$）：$k=\dfrac{4\times3}2+(3-1)=6+2=8$；
② $a_{34}$（$3<4$）：等价于存 $a_{43}$ ⇒ $k=8$（对称分量共用同一空间）；
验算（枚举序）：存放下标依次为 $a_{11}(0),a_{21}(1),a_{22}(2),a_{31}(3),a_{32}(4),a_{33}(5),a_{41}(6),a_{42}(7),a_{43}(8)$ ✓ 与公式吻合。

（2）三角矩阵

下三角矩阵（上三角全是常数 $c$）：存下三角 + 1 个常数单元 ⇒ 空间 $\dfrac{n(n+1)}2+1$，映射公式与对称矩阵下三角完全相同；
上三角矩阵（下三角全是常数）且按行优先存上三角（$i\le j$）： $$k=\frac{(i-1)(2n-i+2)}2+(j-i)$$ 推导：第 $i$ 行前共有 $\sum\limits_{r=1}^{i-1}(n-r+1)=\dfrac{(i-1)(2n-i+2)}2$ 个元素；本行内 $a_{ij}$ 是第 $(j-i+1)$ 个 ⇒ 偏移 $j-i$。
验证（$n=3$）：$a_{11}\to0$，$a_{12}\to1$，$a_{13}\to2$，$a_{22}\to\frac{1\times(6-2+2)}2+0=3$，$a_{23}\to4$，$a_{33}\to\frac{2\times(6-3+2)}2+0=5$ ✓。

（3）三对角矩阵（带状矩阵）

非零元素只出现在对角线及其上下两侧：$|i-j|\le1$，共 $3n-2$ 个。按行优先存入一维数组： $$k=2i+j-3\qquad(i,j\ \text{从 1 开始},\ k\ \text{从 0})$$ 验证序列：$a_{11}(0),a_{12}(1),a_{21}(2),a_{22}(3),a_{23}(4),a_{32}(5),a_{33}(6),a_{34}(7)\dots$——主对角线元素满足 $k=3(i-1)$。
推导小记：首行只有 2 个元素；第 $i\ (\ge2)$ 行之前共 $2+3(i-2)=3i-4$ 个，行内偏移 $j-i+1$ ⇒ $k=(3i-4)+(j-i+1)=2i+j-3$（对 $i=1$ 也成立）。

（4）稀疏矩阵

非零元素个数远小于总元素数（如 < 5%）。两种代表存储：
· 三元组表：每个非零元素存 $(\text{行}, \text{列}, \text{值})$，再记总行数、列数、非零个数——顺序存储，失去随机存取；
· 十字链表：每个非零元素既是所在行链表的结点又是列链表的结点（含行指针 right、列指针 down）——适合非零元素经常变动的场景。
408 考法：给定三元组表问某位置的检索方式（需要顺序扫描）、或比较两种结构适用条件。
四类压缩一句话：对称「存一半、对称换」；三角「存一半 + 常量」（对角线与对称侧别搞反）；三对角「三条带、公式 $2i+j-3$」；稀疏「只存非零、三元组或十字链」。

08典型例题四大计算题型

例 1（出栈序列判断）. 入栈序列固定为 1、2、3、4，判断下列序列是否可能：
（a）3, 4, 2, 1：入 1、2、3 → 出 3 → 入 4 → 出 4 → 出 2 → 出 1 ⇒ 可能 ✓；
（b）4, 3, 1, 2：入 1、2、3、4 → 出 4 → 出 3 → 此时栈顶是 2（1 被 2 压住）⇒ 1 不可能先于 2 出 ⇒ 不可能 ✗。
判据总结：序列中若存在「先输出小、后输出大，而它们在入栈序中夹着未输出的更大元素」就证伪——最稳的方法：动手模拟。
例 2（循环队列全流程计算）. 循环队列长 $M=10$（牺牲单元法），初始 front=rear=0。
① 连续入队 7 个元素：rear 依次后移 ⇒ rear $=7$，front $=0$；
② 出队 3 个：front $=3$，此时元素数 $=(7-3+10)\%10=4$ ✓；
③ 还能再入队几个？从 rear=7 继续入队：8 → 9 → 0 → 1 → 2，当 rear 变为 2 时判满 $(2+1)\%10==3==front$ ⇒ 恰好还能入 5 个（总量 $4+5=9=M-1$ ✓ 与牺牲单元的容量一致）。
易错提醒：元素数公式必须「$+M$ 再取模」，$front>rear$ 时直接相减会得负数。
例 3（三对角矩阵映射）. $n=8$ 的三对角矩阵，按行优先压缩（$k$ 从 0）：求 $a_{45}$ 与 $a_{54}$ 的存储下标，并写出主对角线元素的规律。
① $|4-5|=1$、$|5-4|=1$ 都在带内（否则为 0，不存储）；
② $k(a_{45})=2\times4+5-3=10$；$k(a_{54})=2\times5+4-3=11$；
③ 主对角线：$k=2i+i-3=3(i-1)$ ⇒ $a_{11}\to0$、$a_{22}\to3$、$a_{33}\to6$……
验算（顺推序列）：$a_{11}(0),a_{12}(1),a_{21}(2),a_{22}(3),a_{23}(4),a_{32}(5),a_{33}(6),a_{34}(7),a_{43}(8),a_{44}(9),a_{45}(10)$ ✓ 与公式一致。
例 4（中缀转后缀再练）. 求 (A + B) * C − D 的后缀式。
① 「(」进栈；② A 输出；③ 「+」进栈；④ B 输出；⑤ 「)」⇒ 弹出 + 输出（丢弃括号）；⑥ 「*」进栈；⑦ C 输出；⑧ 「−」：栈顶 * ≥ − ⇒ 弹出 *，再压 −；⑨ D 输出；⑩ 结束弹出 − ⇒ $$\text{结果：}\ A\ B\ +\ C\ *\ D\ -$$ 验算（回代）：A=1,B=2,C=3,D=4：中缀 $(1+2)\times3-4=5$；后缀「1 2 + 3 * 4 −」= $3\times3-4=5$ ✓。

09决策流程与易错点

栈、队列与数组题
├─ 栈
│   ├─ 判空 top==−1 / L->next==NULL；判满 top==MaxSize−1 / 共享栈 top0+1==top1
│   └─ 出栈序列：模拟法逐步推演（卡特兰数只算「有多少种」）
├─ 循环队列
│   ├─ 先认准判满方案：牺牲单元 / size / tag
│   ├─ 元素数 = (rear − front + M) % M
│   └─ 指针移动：一律 (p + 1) % M
├─ 链式队列
│   └─ 出队删到空时：rear 回指 front（头结点）
├─ 表达式
│   ├─ 中缀→后缀：栈顶 ≥ 当前就弹出；括号特殊处理
│   └─ 后缀求值：先弹出的是右操作数
└─ 数组与矩阵
    ├─ 地址：行优先 × 列数 n；列优先 × 行数 m（注意下标起点）
    └─ 压缩：判断矩阵类型 → 套映射公式 → 验证首个元素 k=0

易错点清单

  1. 出栈序列别硬背：一律模拟——「要输出被压在更深位置的小元素」直接判不可能。
  2. 约定先确认：顺序栈 top 指「栈顶元素」还是「栈顶上空」；循环队列 rear 指「队尾元素」还是「其下一个位置」——不同约定判据全部平移。
  3. 共享栈满条件：$top_0+1==top_1$（相遇即满），不是 $\ge$。
  4. 链队出空回指：删到最后一个结点时必须 rear = front，否则尾指针悬空。
  5. 循环队列元素数：$(rear-front+M)\%M$——别漏 $+M$、别漏取模。
  6. 括号匹配三重检查：右括号多余（栈空）、配对不符、左括号多余（结束栈非空）——三处都要判。
  7. 中缀转后缀的弹出条件：「栈顶优先级≥当前」就弹出（保证左结合）；遇到「)」弹到「(」为止，「(」本身不输出。
  8. 后缀求值方向：先弹出的是右操作数——减法除法写反全错。
  9. 地址公式乘对方向：行优先乘「总列数」、列优先乘「总行数」；下标从 1 的题先减 1。
  10. 压缩矩阵：对称矩阵只存下三角时 $i\lt j$ 要换成 $a_{ji}$；三对角公式 $k=2i+j-3$ 自带「首行只有 2 个」的修正，直接套。

主题结论
操作复杂度顺序栈 / 链栈 / 循环队列 / 链队：入、出均 $O(1)$
出栈序列计数卡特兰数 $\frac1{n+1}C_{2n}^{n}$：$n=1,2,3,4$ 对应 $1,2,5,14$
循环队列三方案牺牲单元：空 front==rear、满 (rear+1)%M==front、个数 (rear−front+M)%M；size 法：size==0 / M；tag 法：front==rear 时看 tag（删置 0、插置 1）
共享栈满：top0+1==top1；空：top0==−1 或 top1==MaxSize
链队关键带头结点：空 front==rear；出空时 rear=front
地址公式一维 base+iL；行优先 base+(i·n+j)L；列优先 base+(j·m+i)L
对称矩阵空间 n(n+1)/2；$i\ge j$：$k=\frac{i(i-1)}2+(j-1)$；$i\lt j$ 用对称换算
上三角矩阵$k=\frac{(i-1)(2n-i+2)}2+(j-i)$（行优先存上三角）
三对角矩阵共 $3n-2$ 个；$k=2i+j-3$；对角线 $k=3(i-1)$
稀疏矩阵三元组表（顺序）与十字链表——存储后无随机存取
一句话总纲：栈「后进先出、序列靠模拟」；队列「先进先出、循环靠取模」；数组矩阵「一切靠公式，先辨类型再套公式、代首元素自检」。
