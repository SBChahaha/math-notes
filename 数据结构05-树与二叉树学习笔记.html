01树的基本概念术语与性质

树的递归定义：$n$（$n\ge0$）个结点的有限集合：$n=0$ 是空树；$n>0$ 时有且仅有一个根，其余结点被分成 $m$ 个互不相交的子集，每个子集又是一棵树（根的子树）。
本质：树是「无回路的连通图」——$n$ 个结点恰有 $n-1$ 条边。
术语速记表：
术语含义
双亲 / 孩子结点的上层 / 下层直接相连者
兄弟同一双亲的结点
祖先 / 子孙沿路径向上 / 向下的所有结点（自身除外）
结点的度孩子个数；度为 0 的结点是叶子（叶结点）
树的度所有结点度的最大值
层次根为第 1 层，向下递增；高度（深度）= 最大层次
路径长度路径上的边数
有序树 / 无序树子树有次序 / 无次序
森林$m$ 棵互不相交的树的集合（树删掉根即成森林）
三条基本性质（含推导） ① 结点数与边数：$n$ 个结点的树有 $n-1$ 条边；一般地 $$n=\sum_{i}\text{（结点度数）}+1$$ 推导：每条边对应一个「孩子」，每个结点（除根）恰有一条连向双亲的边 ⇒ 边数 = $n-1$；边数又等于度数总和 ⇒ $n-1=\sum\text{度}$。
② 层上限：度为 $m$ 的树中，第 $i$ 层最多 $m^{\,i-1}$ 个结点（每层都尽量铺满）。
③ 高度上限：高度为 $h$ 的 $m$ 叉树最多 $\dfrac{m^h-1}{m-1}$ 个结点（等比求和 $1+m+\cdots+m^{h-1}$）；反过来，至少 $h$ 个结点（每层至少 1 个）。
例（广义叶子关系）. 设度为 $i$ 的结点数为 $n_i$，则 $$n_0=1+\sum_{i\ge2}(i-1)\,n_i$$ 推导：$n=\sum n_i$，$n-1=\sum i\,n_i$，两式相减整理即得。特例（二叉树）：$n_0=n_2+1$（下一节主角）✓。

02二叉树的概念与性质高频性质

二叉树：每个结点至多有两棵子树，且子树有左右之分（有序）。
与度为 2 的树的区别：① 二叉树可以为空，度为 2 的树至少有 3 个结点；② 二叉树结点只有一个孩子时也要区分左右；③ 二叉树左右有序，是严格的结构。
五种基本形态： 
 ①空     ②仅根     ③根+左     ④根+右      ⑤根+左右
  ∅        A         A          A            A
                   /            \          / \
                  B              B        B   C
满二叉树：高度为 $h$ 且含 $2^h-1$ 个结点（每层都满）。
完全二叉树：与同高度满二叉树按层编号后，前 $n$ 个编号一一对应——特征：只有最后一层可以不满，且空缺只出现在右侧。 
        1
      /   \
     2     3
    / \   /
   4   5 6      ← 完全二叉树：编号连续、最后一层靠左
graph TD
  A((A)) --> B((B))
  A --> C((C))
  B --> D((D))
  B --> E((E))
  E --> H((H))
  C --> F((F))
  C --> G((G))
二叉树五大性质（必背） ① 叶子与双分支：$n_0=n_2+1$；
② 第 $i$ 层最多 $2^{\,i-1}$ 个结点；
③ 高度 $h$ 最多 $2^h-1$ 个结点（达到即为满二叉树）；
④ 完全二叉树的高度：$n$ 个结点的完全二叉树 $$h=\lfloor\log_2n\rfloor+1=\lceil\log_2(n+1)\rceil$$ ⑤ 编号关系（从 1 编号）：结点 $i$ 的左孩子 $2i$、右孩子 $2i+1$（当 $\le n$ 时存在）；双亲 $\lfloor i/2\rfloor$；叶子判据 $i>\lfloor n/2\rfloor$。
证明（①与④，其余直观） ①：结点数 $n=n_0+n_1+n_2$；由「$n-1=$ 度数总和」得 $n-1=n_1+2n_2$。两式相减：$1=n_0-n_2$，即 $n_0=n_2+1$ ✓。
④：完全二叉树前 $h-1$ 层是满的（$2^{h-1}-1$ 个），第 $h$ 层至少 1 个、至多 $2^{h-1}$ 个： $$2^{h-1}\le n\le 2^h-1\ \Longrightarrow\ h-1\le\log_2 n\lt h\ \Longrightarrow\ h=\lfloor\log_2n\rfloor+1\ ✓$$ （对 $n=2^{h}-1$ 取等号也成立。）∎
完全二叉树的「度」规律（选择题常客）：结点总数 $n$ 为奇数时没有度为 1 的结点（$n_1=0$，$n_0=(n+1)/2$）；$n$ 为偶数时恰有一个度为 1 的结点（$n_1=1$，$n_0=n/2$）。配合 $n_0=n_2+1$ 可秒算叶子数。
存储结构：
① 顺序存储：按编号放入数组（空位置 0/标记）——完全二叉树最适用（无空洞）；一般二叉树最坏浪费到 $2^h$ 规模（高度 $h$ 的斜树只有 $h$ 个结点却要 $2^h$ 个位置）；
② 链式存储（二叉链表）： 
typedef struct BiTNode {
    ElemType data;
    struct BiTNode *lchild, *rchild;   // 左右孩子指针
} BiTNode, *BiTree;
空指针计数（线索化的基础）：$n$ 个结点共 $2n$ 个指针域，用掉 $n-1$ 条边的指针，剩 $$2n-(n-1)=n+1$$ 个空指针——线索二叉树正是把它们利用起来。

03二叉树的遍历四序必熟

四种遍历（对上面 Mermaid 图的模型树手工推演）： 
模型树：          A
               /   \
              B     C
             / \   / \
            D   E F   G
                 \
                  H
（即 A( B( D, E(∅,H) ), C( F, G ) )）
遍历顺序口诀本树序列
先序（NLR）根 → 左 → 右A B D E H C F G
中序（LNR）左 → 根 → 右D B E H A F C G
后序（LRN）左 → 右 → 根D H E B F G C A
层序逐层、从左到右A B C D E F G H
推演要点：先序「见根就写」；中序「左到底再写根、然后右」；后序「左右都完才写根」；层序用队列 ✓。
递归代码（三种只差 visit 的位置）： 
void PreOrder(BiTree T) {          void InOrder(BiTree T) {
    if (T != NULL) {                   if (T != NULL) {
        visit(T);          // 根         InOrder(T->lchild); // 左
        PreOrder(T->lchild); // 左        visit(T);           // 根
        PreOrder(T->rchild); // 右        InOrder(T->rchild); // 右
    }                                  }
}                                   }
void PostOrder(BiTree T) {
    if (T != NULL) {
        PostOrder(T->lchild);          // 左
        PostOrder(T->rchild);          // 右
        visit(T);                      // 根
    }
}
复杂度：每个结点恰好访问一次 ⇒ 时间 $O(n)$；递归栈最深为树高 ⇒ 空间 $O(h)$（斜树时 $O(n)$）。
层序遍历（队列是主角）： 
void LevelOrder(BiTree T) {
    InitQueue(Q);
    BiTree p;
    EnQueue(Q, T);
    while (!QueueEmpty(Q)) {
        DeQueue(Q, p);
        visit(p);
        if (p->lchild != NULL) EnQueue(Q, p->lchild);  // 左孩子入队
        if (p->rchild != NULL) EnQueue(Q, p->rchild);  // 右孩子入队
    }
}
「出队一个、入队它的两个孩子」——队列保证了「上一层全部先于下一层出队」✓。
非递归中序（栈模拟，高频考代码）： 
void InOrder2(BiTree T) {
    InitStack(S);  BiTree p = T;
    while (p != NULL || !IsEmpty(S)) {
        if (p != NULL) { Push(S, p); p = p->lchild; }  // 一路向左压栈
        else { Pop(S, p); visit(p); p = p->rchild; }  // 弹出即访问，转向右子树
    }
}
理解：「左到底 → 弹一个访问 → 进它的右子树」循环往复——手写时注意 while 条件是「p 非空或栈非空」。

04由遍历序列构造二叉树还原技术

能唯一确定二叉树的组合
组合能否唯一确定原因
先序 + 中序能先序定根、中序分左右
后序 + 中序能后序定根（末尾）、中序分左右
层序 + 中序能层序定根（首个）、中序分左右
先序 + 后序不能无法区分「只有左孩子」与「只有右孩子」
还原三步法（以先序 + 中序为例）：
① 先序的第一个元素是根；
② 在中序中找到根的位置，左边是左子树、右边是右子树（确定结点数量）；
③ 按数量把先序剩余段也分成两半，对左右子树递归重复。
例（完整还原过程）. 已知先序 ABDEHCFG、中序 DBEHAFCG，还原二叉树。
① 先序首元素 A 为根；中序分块：$\underbrace{D B E H}_{\text{左}}A\underbrace{F C G}_{\text{右}}$；
② 左子树（4 个结点）：先序段 ABDEH 去掉 A 后的 BDEH ⇒ 根 B；中序段 DBEH 分块 $\underbrace{D}_{}\,B\,\underbrace{E H}_{}$ ⇒ 左孩子 D、右子树含 E、H；
③ 右子块 EH：先序段 EH ⇒ 根 E；中序段 EH 分块 $E\,\underbrace{H}_{}$（E 左边无内容）⇒ H 是 E 的右孩子；
④ 右子树（3 个结点）：先序段 CFG ⇒ 根 C；中序段 FCG 分块 $\underbrace{F}_{}\,C\,\underbrace{G}_{}$ ⇒ F 左、G 右；
⑤ 还原完成（与 §3 模型树一致）；验算：对该树求后序 = D H E B F G C A，与推演一致 ✓（还原正确性的自检）。
后序 + 中序怎么手动：后序的最后一个元素是根，其余步骤完全相同（后序段按「左子树结点数」从前面分割——因为后序是「左、右、根」）。
层序 + 中序怎么手动：层序的第一个元素是根；之后的元素按「先左子树后右子树」的顺序出现，用中序分块逐层落位。

05线索二叉树空指针再利用

动机：二叉链表有 $n+1$ 个空指针——把它们指向某种遍历次序下的前驱/后继，就叫线索化。利用线索遍历不需要栈、不需要递归（$O(1)$ 空间）。
标记含义：ltag / rtag：0 = 指向孩子（原本的指针）；1 = 指向前驱/后继（线索）。
线索二叉树结构： 
typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;          // 0：孩子；1：线索
} ThreadNode, *ThreadTree;
三种线索：按遍历次序不同分为中序/先序/后序线索二叉树；408 最常考中序线索。
中序线索化代码（递归，pre 始终指向上一个访问结点）： 
void InThread(ThreadTree p, ThreadTree &pre) {
    if (p != NULL) {
        InThread(p->lchild, pre);            // 递归左子树
        if (p->lchild == NULL) {             // 左空 ⇒ 建前驱线索
            p->lchild = pre;  p->ltag = 1;
        }
        if (pre != NULL && pre->rchild == NULL) { // 前驱右空 ⇒ 建后继线索
            pre->rchild = p;  pre->rtag = 1;
        }
        pre = p;                             // 更新前驱
        InThread(p->rchild, pre);            // 递归右子树
    }
}
观察：「后继线索」是在访问到下一个结点时才补上的——所以传入的 pre 必须是引用。
中序线索找「第一个」与「后继」（选择题必会）： 
ThreadNode *FirstNode(ThreadNode *p) {   // 中序第一个结点：最左下
    while (p->ltag == 0) p = p->lchild;
    return p;
}
ThreadNode *NextNode(ThreadNode *p) {    // p 的中序后继
    if (p->rtag == 1) return p->rchild;  // 线索直接给出
    else return FirstNode(p->rchild);    // 否则是右子树的第一个
}
对称地：中序最后结点 = 最右下；中序前驱 = 若 ltag==1 取 lchild，否则左子树的最右下结点。
三种线索的「难点不对称」（常考辨析）：
· 中序线索：找前驱、后继都容易；
· 先序线索：找后继容易（右孩子或右子树的先序首结点），找前驱困难（可能需要双亲信息，因为左子树根是自身前驱？——错！先序中「前驱」要分情况：若 p 是左孩子则前驱是双亲…所以先序线索找前驱需要三叉链表）；
· 后序线索：找前驱容易、找后继困难。
规律记忆：「先序怕前驱、后序怕后继、中序最完美」。

06树的存储结构与树、森林转换与遍历对应

三种存储结构：
① 双亲表示法：数组存每个结点的「数据 + 双亲下标」（根为 $-1$）——找双亲 $O(1)$，找孩子 $O(n)$； 
typedef struct { ElemType data; int parent; } PTNode;
typedef struct { PTNode nodes[MAX_TREE_SIZE]; int n; } PTree;
② 孩子表示法：顺序表 + 每结点挂一个孩子链表（找孩子快、找双亲慢——可与双亲表示法组合）；
③ 孩子兄弟表示法（重点）：两个指针——左指针指第一个孩子、右指针指下一个兄弟： 
typedef struct CSNode {
    ElemType data;
    struct CSNode *firstchild, *nextsibling;
} CSNode, *CSTree;
它已经就是二叉树形态 ⇒ 天然引出「树 → 二叉树」转换。
树 → 二叉树（左孩子右兄弟）：对每个结点，左指针连第一个孩子、右指针连下一个兄弟。森林 → 二叉树：第一棵树根作根，第一棵树的子树森林与其余树依次连在右链上。
例（一棵树转成二叉树）. 原树（有序）： 
原树：        A           二叉树（左孩子右兄弟）：
           / | \              A
          B  C  D            /
         / \    |           B
        E   F   G            \
                               C
                                \
                                 D
                                /
                               G
        （B 的孩子 E、F 挂在 B 的左侧链）
转换规则逐点应用：A 的左 = 第一个孩子 B，A 的右 = ∅；B 的左 = E、右 = 下一个兄弟 C；E 的右 = 下一个兄弟 F；C 的右 = D；D 的左 = G。（完整形态：A(l=B)，B(l=E, r=C)，E(r=F)，C(r=D)，D(l=G)。）
遍历对应关系（必背，选择题原话）
原结构遍历对应二叉树的遍历
树先根遍历（根→各子树）先序遍历
树后根遍历（各子树→根）中序遍历
森林先序遍历（逐树先根）先序遍历
森林中序遍历（逐树后根）中序遍历
一句话记忆：「树/森林的先序都对应二叉树先序；树/森林的后根（中序）都对应二叉树中序——左孩子右兄弟的转换把「兄弟关系」藏进了二叉树的右链，所以后根遍历落到中序上。」
用途：有了对应关系，树的遍历无需专门算法——转成二叉树后套四种遍历即可（这也是「孩子兄弟表示法」被称为「二叉树表示法」的原因）。

07哈夫曼树与哈夫曼编码贪心经典

带权路径长度（WPL）：每个叶子有权 $w_i$、到根的路径长度（边数）为 $l_i$： $$\text{WPL}=\sum_{i=1}^{n}w_i\,l_i$$ 哈夫曼树：WPL 最小的二叉树（也叫最优二叉树）——叶子带权、让大权重的叶子离根更近。
构造算法（贪心，必会手绘）：① 所有权值看成 $n$ 棵单结点树；② 每次取出权值最小的两棵合并为新结点（权 = 两者之和）；③ 重复直到只剩一棵树。
两条性质（选择题）：哈夫曼树共有 $2n-1$ 个结点（$n$ 个叶子 + $n-1$ 次合并产生的新结点）；不存在度为 1 的结点（每次合并都把两棵并成双分支）。
例 1（构造全过程：权 {2, 4, 5, 7}）.
① 取最小 2、4 合并 ⇒ 新结点 6（集合：5, 6, 7）；
② 取最小 5、6 合并 ⇒ 新结点 11（集合：7, 11）；
③ 取 7、11 合并 ⇒ 根 18。树形： 
              18
            /    \
          7       11
                 /   \
                5     6
                    /   \
                   2     4
④ WPL $=7\times1+5\times2+2\times3+4\times3=7+10+6+12=35$；
捷径公式（必记）： $$\text{WPL}=\sum\text{（每次合并产生的新结点权值）}=6+11+18=35\ ✓$$ 两者一致——遇到大权值集合用「合并和」秒算。
例 2（哈夫曼编码）. 四个字符频率 a:2、b:4、c:5、d:7，构造前缀编码：
① 树与例 1 相同；约定左 0 右 1（7 在左、11 在右；11 内 c 在左、6 在右；6 内 a 左 b 右）： 
d = 0
c = 10
a = 110
b = 111
② 前缀性检查：没有任何编码是另一编码的前缀 ⇒ 解码无歧义 ✓；
③ 加权码长（= WPL）：$7\times1+5\times2+2\times3+4\times3=35$；平均码长 $=35/18\approx1.94$ 位/字符；
说明：哈夫曼编码不唯一（左右可互换、同权可换序），但最小 WPL 唯一。
为什么编码前缀性天然成立：所有字符都在叶子——从根到叶的路径不会被别的叶子「截断」，这正是「编码对应叶子」的设计用意。

08并查集双亲数组 + 两大优化

并查集（不相交集合）：支持三种操作——Initial（初始化）、Find（查集合/根）、Union（合并两集合）。典型用途：无向图的连通分量、Kruskal 最小生成树（第六章）。
存储：双亲表示法的数组——每个元素存双亲下标；根结点存负数（绝对值 = 该树的结点数）。
三个操作（王道标准版）： 
int UFSets[SIZE];
void Initial(int S[]) {
    for (int i = 0; i < SIZE; i++) S[i] = -1;   // 各自为根，规模 1
}
int Find(int S[], int x) {
    int root = x;
    while (S[root] >= 0) root = S[root];        // 一路向上找根
    while (x != root) {                         // 【路径压缩】
        int t = S[x];
        S[x] = root;
        x = t;
    }
    return root;
}
void Union(int S[], int a, int b) {
    int ra = Find(S, a), rb = Find(S, b);
    if (ra == rb) return;                       // 已同属一个集合
    if (S[ra] > S[rb]) { S[rb] += S[ra]; S[ra] = rb; } // ra 小 ⇒ 并入 rb
    else               { S[ra] += S[rb]; S[rb] = ra; } // 【小树并入大树】
}
两个优化的含义：① 按大小合并（小树接大树根）把树高压住 $O(\log n)$；② 路径压缩把查找路径上所有点直接挂到根上——两者结合后单次操作近似 $O(1)$（均摊）。
例（逐步演练）. 依次执行 Union(0,1)、Union(2,3)、Union(1,2)、Find(3)。
操作数组变化（下标 0–3）说明
初始[-1, -1, -1, -1]各自为根
Union(0,1)[-2, 0, -1, -1]规模相同，0 作根，1 挂 0
Union(2,3)[-2, 0, -2, 2]2 作根，3 挂 2
Union(1,2)[-4, 0, 0, 2]根 0 与根 2 规模相同 ⇒ 2 并入 0：S[0]=−4、S[2]=0
Find(3)[-4, 0, 0, 0]路径 3→2→0 压缩：3 与 2 都直接挂 0
验算：最后 S[0]=−4 表示整棵树 4 个结点全部连通；查 3 的根：S[3]=0 一步到位 ✓。

09典型例题性质·还原·哈夫曼·并查集

例 1（完全二叉树性质计算）. 一棵完全二叉树有 1000 个结点，求叶子结点数与树高。
① 结点总数 $n=1000$ 为偶数 ⇒ 恰有一个度为 1 的结点：$n_1=1$；
② $n_0+n_2=999$ 且 $n_0=n_2+1$ ⇒ $2n_0-1=999$ ⇒ $n_0=500$；
③ 高度：$2^9=512\le1000<1024=2^{10}$ ⇒ $h=\lfloor\log_21000\rfloor+1=9+1=10$。
答案：叶子 500 个、高度 10 ✓。
例 2（后序 + 中序还原）. 已知后序 DHEBFGCA、中序 DBEHAFCG，还原二叉树。
① 后序末位 A ⇒ 根 A；中序分块 $DBEH\,|\,A|\,FCG$；后序分为 $DHEB\,|\,FGC\,|\,A$；
② 左子树（后序段 DHEB）：末位 B ⇒ 根 B；中序段 DBEH 分为 $D\,|\,B|\,EH$；后序段分为 $D\,|\,HE\,|\,B$；
③ D 是叶子；EH 段（后序 HE）：末位 E ⇒ 根 E；中序段 EH ⇒ E 无左、H 是右孩子（后序中 H 位于 E 之前正对应「右子树先于根」）✓；
④ 右子树（后序段 FGC）：末位 C ⇒ 根 C；中序 FCG ⇒ F 左、G 右；
⑤ 验算：对还原结果求先序 = ABDEHCFG（与 §3 模型树一致）✓。
例 3（哈夫曼：权 {1, 3, 4, 5}）.
① 合并 1+3=4（集合 4, 4, 5）；② 合并 4+4=8（集合 5, 8）；③ 合并 5+8=13 ⇒ 根；
④ WPL（捷径）= $4+8+13=\mathbf{25}$；
验算（按深度）：5 深度 1、原 4 深度 2、1 与 3 深度 3 ⇒ $5+8+3+9=25$ ✓；
⑤ 编码（左 0 右 1）：5=0，4=10，1=110，3=111——前缀性成立，加权长 25 ✓。
例 4（并查集轨迹快练）. 依次 Union(1,2)、Union(3,4)、Union(2,3)（下标 0 起，初始全 −1）：
① Union(1,2)：$[-1,-2,1,-1,-1]$（2 挂 1）；
② Union(3,4)：$[-1,-2,1,-2,3]$（4 挂 3）；
③ Union(2,3)：根 1 与根 3 规模都为 2 ⇒ 合并为 $S[1]=-4,\ S[3]=1$ ⇒ $[-1,-4,1,1,3]$。
验证：Find(4)：4→3→1，根为 1，路径压缩后 S[4]=1、S[3]=1 ✓。

10决策流程与易错点

树与二叉树题
├─ 性质计算
│   ├─ n₀=n₂+1（二叉树/哈夫曼通用）；完全二叉树看 n 的奇偶定 n₁
│   ├─ 层最多 2^(i−1)；高最多 2^h−1；完全树高 ⌊log₂n⌋+1
│   └─ 编号：左 2i、右 2i+1、父 ⌊i/2⌋、叶 i>⌊n/2⌋
├─ 遍历
│   ├─ 手推四序（先/中/后/层）注意子树整体性
│   ├─ 还原：先/后/层 + 中序唯一；先+后不唯一
│   └─ 非递归：中序=一路向左压栈、弹出访问转右
├─ 线索：找前驱/后继（中序最顺；先序怕前驱、后序怕后继）
├─ 树/森林：左孩子右兄弟转换；树先根=BT先序、树后根=BT中序
├─ 哈夫曼：取两个最小合并、WPL=合并和、前缀编码
└─ 并查集：根存负数（规模）；按大小合并 + 路径压缩

易错点清单

  1. $n_0=n_2+1$ 的适用面：任何二叉树与哈夫曼树成立；一般 $m$ 叉树要用广义公式 $n_0=1+\sum(i-1)n_i$。
  2. 完全二叉树 $n_1$：$n$ 奇数 ⇒ $n_1=0$；$n$ 偶数 ⇒ $n_1=1$——先定 $n_1$ 再解方程。
  3. 两个高度公式等价：$\lfloor\log_2n\rfloor+1=\lceil\log_2(n+1)\rceil$，套哪个都行。
  4. 先序 + 后序不唯一：单孩子子树无法区分左右——考试如果给这两组序又要求唯一答案，必有陷阱。
  5. 遍历对应方向：树先根 = 二叉树先序；树后根 = 二叉树中序——最常见记反点。
  6. 线索的前驱/后继是「遍历次序」上的：不是树上的父子关系；且先序线索找前驱难、后序线索找后继难。
  7. 空指针数：$2n-(n-1)=n+1$ 个——线索化的「原料」。
  8. 哈夫曼树的形状不唯一：但 WPL 唯一最小；不存在度为 1 的结点；共 $2n-1$ 个结点。
  9. 并查集合并方向：根存负数，$-2$ 比 $-4$「小」——别按普通数值比较把大树并进小树。
  10. 层序用队列、中序非递归用栈：循环条件「p 非空 或 栈非空」——写成「且」就死循环。

11速查表与能力自查

主题结论
结点与边树：$n$ 结点 $n-1$ 边、$n=\sum\text{度}+1$
二叉树核心性质$n_0=n_2+1$；第 $i$ 层最多 $2^{i-1}$；高 $h$ 最多 $2^h-1$；完全树高 $\lfloor\log_2n\rfloor+1$
完全二叉树编号左 $2i$、右 $2i+1$、父 $\lfloor i/2\rfloor$、叶子 $i>\lfloor n/2\rfloor$；$n$ 偶 ⇒ $n_1=1$
链式存储二叉链表空指针 $n+1$ 个（线索来源）
遍历序列（模型树 A(B(D,E(,H)),C(F,G))）先 ABDEHCFG；中 DBEHAFCG；后 DHEBFGCA；层 ABCDEFGH
还原组合先+中、后+中、层+中 ⇒ 唯一；先+后 ⇒ 不唯一
线索ltag/rtag：0 孩子、1 线索；中序找后继：rtag=1 取右，否则右子树最左下
树/森林遍历对应树先根 = BT 先序；树后根 = BT 中序；森林先序 = BT 先序；森林中序 = BT 中序
哈夫曼$2n-1$ 个结点、无度 1 结点；$\text{WPL}=\sum$ 合并值；前缀编码
并查集根存负数（规模）；Union 小树并入大树；Find 带路径压缩；均摊近 $O(1)$
一句话总纲：性质靠 $n_0=n_2+1$ 与编号公式秒算；遍历靠「整棵子树一起走」；还原靠「根定序 + 中序分块」；哈夫曼靠「取两最小合并」；并查集靠「负数规模 + 压缩」。
