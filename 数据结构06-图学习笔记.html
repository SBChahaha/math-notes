01图的基本概念概念

图：$G=(V,E)$——$V$ 为顶点集、$E$ 为边集。
· 有向图：边是弧 $\langle v,w\rangle$（$v$ 弧尾 → $w$ 弧头，有方向）；
· 无向图：边 $(v,w)$ 无方向；
· 简单图：不存在重复边、不存在自环（408 默认讨论简单图）；多重图：允许二者。
· 网：带权图（边有权值）。
三组核心计数（必背） ① 完全图：任意两顶点间都有边——无向完全图边数 $\dfrac{n(n-1)}2$；有向完全图弧数 $n(n-1)$；
② 度的总和：无向图 $\sum\deg(v)=2e$（每条边贡献两个度）；有向图 $\sum\text{入度}=\sum\text{出度}=e$（度 = 入度+出度）；
③ 连通的最少边：连通无向图至少 $n-1$ 条边（就是树）；强连通有向图至少 $n$ 条弧（一个环）。
路径与回路：顶点序列 $v_1,v_2,\dots,v_k$（相邻两项有边）；路径长度 = 边的条数。
· 简单路径：顶点不重复；简单回路：除首尾外不重复的回路；
· 顶点 $v$ 到自身长度为 0 的路径存在（平凡）。
连通性：
· 无向图：任意两顶点间有路径 ⇒ 连通图；否则分成若干连通分量（极大连通子图）；
· 有向图：任意两顶点双向可达 ⇒ 强连通图；分成若干强连通分量；
· 生成树：连通图含全部 $n$ 个顶点、$n-1$ 条边的极小连通子图；非连通图得到生成森林（每个连通分量一棵生成树）。

02图的存储结构四件套

（1）邻接矩阵（稠密图首选）

#define MaxVertexNum 100
typedef struct {
    char Vex[MaxVertexNum];                 // 顶点表
    int Edge[MaxVertexNum][MaxVertexNum];   // 邻接矩阵（1/0 或权值）
    int vexnum, arcnum;
} MGraph;
· 无向图的矩阵对称；空间恒为 $O(n^2)$（与边数无关，稀疏图浪费）；
· 判断两点间是否有边 $O(1)$；
· 求度：无向图某行（列）之和 = 该点度；有向图行和 = 出度、列和 = 入度；
· 适用：稠密图；不适合频繁增删顶点。

（2）邻接表（稀疏图首选）

typedef struct ArcNode {          // 边结点
    int adjvex;                   // 邻接点在顶点表中的下标
    struct ArcNode *next;         // 下一条边
} ArcNode;
typedef struct VNode {            // 顶点
    char data;
    ArcNode *first;               // 第一条边
} VNode, AdjList[MaxVertexNum];
typedef struct {
    AdjList vertices;
    int vexnum, arcnum;
} ALGraph;
· 空间：无向 $O(n+2e)$、有向 $O(n+e)$；
· 无向图度 = 该顶点边链表的结点数；有向图出度易求（链表长度），入度难求（需遍历全表——除非建逆邻接表）；
· 邻接表不唯一（边结点的次序可任意）——这直接导致 BFS/DFS 序列与生成树不唯一。

（3）十字链表（有向图专供）

每个弧一个结点，同时挂在「起点的出边链」与「终点的入边链」上： 
typedef struct ArcBox {
    int tailvex, headvex;               // 弧尾、弧头的下标
    struct ArcBox *hlink, *tlink;       // 弧头相同链、弧尾相同链
} ArcBox;
typedef struct VexNode {
    char data;
    ArcBox *firstin, *firstout;         // 入边、出边
} VexNode;
· 空间 $O(n+e)$；入度、出度都易求（各扫对应链）；
· 适用：有向图的频繁增删边场景。

（4）邻接多重表（无向图专供）

每条边只存一个结点（邻接表存两份，删除时要两头改）： 
typedef struct EBox {
    int ivex, jvex;                     // 边连接的两个顶点
    struct EBox *ilink, *jlink;         // 各自下一条边
    /* 可加标记位 mark 表示是否访问过 */
} EBox;
· 空间的边结点数 = $e$（邻接表为 $2e$）；
· 适用：无向图的边频繁删除/遍历标记场景。
四种结构速记：矩阵「稠密、随机判边、$O(n^2)$」；邻接表「稀疏、出度快、入度慢」；十字链表「有向图 + 出入度都要」；邻接多重表「无向图 + 边只存一次」。

03图的遍历：BFS队列·分层

广度优先（BFS）：从起点出发，先访问所有「距离 1」的顶点，再访问「距离 2」……用队列实现「先来先扩展」，用 visited 数组防重复。
bool visited[MaxVertexNum];
void BFS(Graph G, int v) {          // 从顶点 v 出发，一次连通分量
    visit(v);  visited[v] = true;
    InitQueue(Q);  EnQueue(Q, v);
    while (!QueueEmpty(Q)) {
        DeQueue(Q, v);
        for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w))
            if (!visited[w]) {
                visit(w);  visited[w] = true;
                EnQueue(Q, w);       // 入队：留待以后扩展
            }
    }
}
/* 非连通图：外层 for 每个未访问顶点各调一次 → 生成森林 */
层数视角：入队次序恰好是「距离不降」的——队列天然保证了分层。
例（对贯穿示例图从 1 出发的 BFS，邻接次序升序）. 
邻接表：1:2,3  2:1,4,5  3:1,6,7  4:2,8  5:2,8  6:3,8  7:3,8  8:4,5,6,7

12, 3⟨2, 3⟩1, 2, 3
24, 5⟨3, 4, 5⟩1, 2, 3, 4, 5

BFS 序列：1, 2, 3, 4, 5, 6, 7, 8；BFS 生成树边（首次访问时的边）：$(1,2),(1,3),(2,4),(2,5),(3,6),(3,7),(4,8)$ 共 7 条 = $n-1$ ✓。
例（BFS 求无权图单源最短路径）. 在 BFS 中把「第几层」记下来，即最短距离： 
d[u] = 0;  // 起点距离
/* 发现 w 时 */ d[w] = d[u] + 1;   // 层数 +1
对示例图从 1 出发：$d(1)=0$；$d(2)=d(3)=1$；$d(4)=d(5)=d(6)=d(7)=2$；$d(8)=3$——如 1 到 8 的最短路 1→2→4→8 或 1→3→6→8 长度均为 3 ✓。
适用范围警告：BFS 求最短路只对无权图（边权为 1 才等价于层数；带权图要用 Dijkstra，§6）。
BFS 复杂度与性质 时间复杂度：邻接矩阵 $O(n^2)$（每顶点扫一整行）；邻接表 $O(n+e)$（每顶点出边扫一次）。空间 $O(n)$（队列 + visited）。
不唯一性：邻接表的次序不同 ⇒ BFS 序列与生成树可能不同——考试给定了邻接次序才谈唯一答案。

04图的遍历：DFS递归·深钻

深度优先（DFS）：从起点出发，沿一条路一直钻到底，走不动再回退找岔路——用递归（系统栈）实现。
void DFS(Graph G, int v) {
    visit(v);  visited[v] = true;
    for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w))
        if (!visited[w])
            DFS(G, w);              // 递归深入
}
非递归版（显式栈）：入栈即访问的变体——把「Push 未访问邻居」循环替代递归（注意与递归顺序的细微差别，考试以递归版为主）。
例（对贯穿示例图从 1 出发的 DFS 递归轨迹）. 
DFS(1)→访问1→邻居2未访问→DFS(2)
  DFS(2)：邻居1已访→4未访→DFS(4)
    DFS(4)：邻居2已访→8未访→DFS(8)
      DFS(8)：邻居4已访→5未访→DFS(5)
        DFS(5)：邻居2、8都已访→回退
      DFS(8)续：6未访→DFS(6)
        DFS(6)：邻居3未访→DFS(3)
          DFS(3)：邻居1已访→6已访→7未访→DFS(7)
            DFS(7)：邻居3、8都已访→回退
      （全部回退，遍历结束）
DFS 序列：1, 2, 4, 8, 5, 6, 3, 7；DFS 生成树边：$(1,2),(2,4),(4,8),(8,5),(8,6),(6,3),(3,7)$ 共 7 条 ✓。
观察：与 BFS 序列（1,2,3,4,5,6,7,8）截然不同——但两种都是合法遍历，起点、邻接次序一变序列就变。
DFS 复杂度与性质 时间：邻接矩阵 $O(n^2)$、邻接表 $O(n+e)$（与 BFS 相同）；空间：递归栈最深 $O(n)$（链状图）。
· DFS 天然适合「一条路走到黑」的问题：判连通、数连通分量、找所有路径、判环（无向图 DFS 遇已访问且非父结点 ⇒ 有环）；
· 非连通图同样靠外层循环 → DFS 生成森林。
BFS vs DFS 一句话对答：「队列 vs 栈；分层最短 vs 一条路深钻；复杂度公式相同；生成树都可能不唯一；无权图最短路找 BFS、连通性/环检测通常用 DFS」。

05最小生成树（Prim / Kruskal）贪心双雄

最小生成树（MST）：连通网中边权总和最小的生成树。两大算法都是贪心——先记结论：MST 的边数 = $n-1$；等权时 MST 可能不唯一，但最小权值总和唯一。
贯穿示例（6 顶点带权图）. 
顶点 1–6，边与权：
(1,2)=6  (1,3)=1  (1,4)=5  (2,3)=5  (2,5)=3
(3,4)=5  (3,5)=6  (3,6)=4  (4,6)=2  (5,6)=6

（1）Prim：加点法（从任一顶点开始「向集合外生长」）

流程：把起点放进集合 $U$；每次从「一端在 $U$、另一端不在 $U$」的边中选权最小的，把新顶点拉进 $U$；重复 $n-1$ 次。
例（从 1 出发的 Prim 全过程）.
轮已选集合 U跨边中最小者选中累计权
1{1}(1,3)=1(1,3)1
2{1,3}(3,6)=4（击败 (1,4)=5、(2,3)=5…）(3,6)5
3{1,3,6}(6,4)=2(4,6)7
4{1,3,6,4}(3,2)=5(2,3)12
5{1,3,6,4,2}(2,5)=3(2,5)15
MST 边集：$(1,3),(3,6),(4,6),(2,3),(2,5)$，总权 15 ✓（6 个顶点 5 条边）。
注意：第 4 轮中 $(2,5)=3$ 虽最小，但两端都不在 $U$ 内——不是候选，这就是 Prim「跨边」的含义。
Prim 复杂度朴素实现（维护 distToU 数组）：每轮选最小 $O(n)$、松弛 $O(n)$，共 $n-1$ 轮 ⇒ $O(n^2)$——与边数无关，适合稠密图。

（2）Kruskal：加边法（按权从小到大加边，不成环就要）

流程：把所有边按权排序；依次取出最小边，若它的两个端点当前不在同一并查集（不会成环）就加入 MST 并合并集合；凑满 $n-1$ 条边为止。
例（Kruskal 全过程）. 边排序：1:(1,3)；2:(4,6)；3:(2,5)；4:(3,6)；5:(1,4),(2,3),(3,4)；6:(1,2),(3,5),(5,6)（同权组内次序任意）。

(1,3)1两集合✓ 加入1
(4,6)2两集合✓ 加入3
(2,5)3两集合✓ 加入6
(3,6)4{1,3} 与 {4,6} 两集合✓ 加入（大集合合并）10
(1,4)51、4 已在同集合✗ 成环，跳过10
(2,3)5{1,3,4,6} 与 {2,5} 两集合✓ 加入 ⇒ 已 $n-1=5$ 条15
与 Prim 结果对比：边集 $(1,3),(4,6),(2,5),(3,6),(2,3)$ 与 Prim 相同（权总和必同为 15）✓。
Kruskal 复杂度排序 $O(e\log e)$ + 并查集判环（近 $O(1)$）⇒ 总 $O(e\log e)$——只看边数，适合稀疏图。
选择口诀：稠密图（边多）用 Prim（$O(n^2)$ 不吃亏）；稀疏图（边少）用 Kruskal（$O(e\log e)$ 更小）。

06最短路径（Dijkstra / Floyd）两个必考算法

（1）Dijkstra：单源最短路径（非负权）

贪心思想：维护 dist[]（起点到各点的当前最短估计）与 S[]（已确定的点）。每次从「未确定」中取出 dist 最小者确定，再用它松弛所有邻居：若 $dist[u]+w(u,w)\lt dist[w]$ 就更新。
void Dijkstra(MGraph G, int v0, int dist[], int path[]) {
    /* 初始化：dist[w] = v0 到 w 的直接边权（无直接边为 ∞）；S[] 全 false */
    for (int round = 1; round < G.vexnum; round++) {
        int u = /* 未确定点中 dist 最小者 */;
        S[u] = true;                        /* 定点：此刻已是最优 */
        for (int w = 1; w <= G.vexnum; w++) /* 松弛 */
            if (!S[w] && dist[u] + G.Edge[u][w] < dist[w]) {
                dist[w] = dist[u] + G.Edge[u][w];
                path[w] = u;                /* 记录前驱，用于还原路径 */
            }
    }
}
为什么正确（非负权关键）：当前 dist 最小者不可能再被绕远路缩短（任何绕路都要再加非负权）——所以可以「定死」。
例（从顶点 1 出发，对 §5 示例图跑 Dijkstra）.
轮dist（1,2,3,4,5,6）本选定点松弛效果
初值0, 6, 1, 5, ∞, ∞——
10, 6, 1, 5, 7, 53（dist 1）5←7（1+6）；6←5（1+4）；2、4 不优
20, 6, 1, 5, 7, 54（dist 5）6 处 5+2=7 > 5，不变
30, 6, 1, 5, 7, 56（dist 5）5 处 5+6=11 > 7，不变
40, 6, 1, 5, 7, 52（dist 6）5 处 6+3=9 > 7，不变
50, 6, 1, 5, 7, 55（dist 7）完成
最终：$d(2)=6,\ d(3)=1,\ d(4)=5,\ d(5)=7,\ d(6)=5$ ✓。
验算（1→5）：候选路径 1→3→5 $=1+6=7$、1→2→5 $=6+3=9$、1→3→6→5 $=1+4+6=11$ ⇒ 最小 7，与表中结果一致 ✓。
复杂度：$O(n^2)$；每轮「选最小」用堆可降到 $O((n+e)\log n)$（408 手推按朴素 $O(n^2)$）。

（2）Floyd：各顶点对最短路径（DP 三循环）

void Floyd(int A[][N], int n) {   /* A 初值：邻接矩阵（∞=无路，对角线 0） */
    for (int k = 1; k <= n; k++)              /* 中转点 k */
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                if (A[i][j] > A[i][k] + A[k][j])   /* 经 k 中转更短？ */
                    A[i][j] = A[i][k] + A[k][j];
}
递推含义：$A^{(k)}[i][j]=\min\left(A^{(k-1)}[i][j],\ A^{(k-1)}[i][k]+A^{(k-1)}[k][j]\right)$——「只允许用前 $k$ 个点中转」的最短路。三重循环 ⇒ $O(n^3)$；允许负权，但不能有负环。
例（三顶点小例：1→2=6、1→3=3、3→2=2）. 
初始矩阵 D⁰：         k=3 时发现更短：
     1   2   3              d[1][2] = min(6, d[1][3]+d[3][2])
 1  [ 0   6   3 ]                      = min(6, 3+2) = 5  ⇒ 更新 ✓
 2  [ ∞   0   ∞ ]        路径：1 → 3 → 2（长度 5 < 6）
 3  [ ∞   2   0 ]
验算：$k=1,2$ 轮无更新（无更多中转可能）；最终 $d(1,2)=5$ ✓。
Dijkstra vs Floyd 对答表：
维度DijkstraFloyd
范围单源到所有点任意两点间
思想贪心 + 松弛动态规划（三重循环）
复杂度$O(n^2)$$O(n^3)$
负权不允许允许边负、不允许负环
适用单源问题全源 / 小规模稠密图

07拓扑排序AOV 网

AOV 网：用顶点表示活动、用弧表示活动之间先后关系的有向无环图（DAG）。
拓扑排序：把全部顶点排成线性序列，使图中每条弧都「从前指向后」。存在拓扑序 ⇔ 图中无环。
算法流程（Kahn 法）：
① 统计各顶点的入度，把所有入度为 0 的顶点入栈（或队列）；
② 反复出栈一个顶点输出，并「删除」它的所有出边——对应邻接点的入度减 1；入度减到 0 就入栈；
③ 重复直到栈空。若输出的顶点数 < n ⇒ 图中有环（排序失败）。
bool TopologicalSort(Graph G) {
    InitStack(S);
    for (int i = 0; i < G.vexnum; i++)
        if (indegree[i] == 0) Push(S, i);      // 所有「源」入栈
    int count = 0;
    while (!StackEmpty(S)) {
        Pop(S, i);  print(i);  count++;
        for (ArcNode *p = G.vertices[i].first; p; p = p->next) {
            int w = p->adjvex;
            indegree[w]--;                     // 删边：邻居入度减一
            if (indegree[w] == 0) Push(S, w);
        }
    }
    return count == G.vexnum;                  // false：存在环
}
复杂度：$O(n+e)$（顶点入栈一次、每条边处理一次）。

08关键路径AOE 网

AOE 网：用边表示活动（带权=持续时间）、顶点表示事件的带权有向无环图。源点（唯一入度 0）、汇点（唯一出度 0）分别代表工程开始与结束。
关键路径：源点到汇点的最长路径——其长度就是完成整个工程所需的最短工期；路径上的活动叫关键活动（没有一点时间余量）。
四个量的计算流程：
① 事件最早发生时间 $ve$：按拓扑序递推，源点 $ve(\text{源})=0$， $$ve(j)=\max_{\langle i,j\rangle}\left\{ve(i)+w(i,j)\right\}$$ ② 事件最迟发生时间 $vl$：按逆拓扑序递推，汇点 $vl(\text{汇})=ve(\text{汇})$， $$vl(i)=\min_{\langle i,j\rangle}\left\{vl(j)-w(i,j)\right\}$$ ③ 活动最早/最迟开始：对活动 $a=\langle i,j\rangle$： $$e(a)=ve(i),\qquad l(a)=vl(j)-w(i,j)$$ ④ 时间余量 $l-e$：余量为 0 的活动是关键活动；由关键活动连成的源→汇路径即关键路径。
例（小型 AOE：v1→v2=2，v2→v4=3，v1→v3=3，v3→v4=4）.
① 求 ve（拓扑序 v1,v2,v3,v4）：$ve(1)=0$；$ve(2)=0+2=2$；$ve(3)=0+3=3$；$ve(4)=\max(2+3,\ 3+4)=7$。
② 求 vl（逆序 v4,v3,v2,v1）：$vl(4)=7$；$vl(3)=7-4=3$；$vl(2)=7-3=4$；$vl(1)=\min(4-2,\ 3-3)=0$。
③ 活动表：

a: 1→2 (2)04 − 2 = 22否
b: 2→4 (3)27 − 3 = 42否
c: 1→3 (3)03 − 3 = 00是
d: 3→4 (4)37 − 4 = 30是
④ 结论：关键路径 v1→v3→v4，工期 7 ✓；活动 a、b 各有 2 个时间单位余量（晚开工 2 天不影响总工期）。
三条必考辨析：
① 关键路径是最长路径（不是最短！）；② 关键路径可能不止一条（多条同为最长）；③ 缩短某个关键活动不一定缩短总工期——它可能把别的路径变成新的最长路径（关键路径发生转移），而原来缩短的活动反而出现余量。反之，非关键活动决不能随意延误超过它的余量。

09典型例题计算·判断·辨析

例 1（度与边：经典计算）. 一个无向图有 16 条边，其中 3 个顶点的度为 4、4 个顶点的度为 3，其余顶点的度均小于 3。问该图至少有多少个顶点？
① 由 $\sum\deg=2e$ 得总度数 $=32$；
② 已知 7 个顶点贡献 $3\times4+4\times3=24$，剩余度数 $=32-24=8$；
③ 剩余顶点度 < 3，即最多为 2——为使顶点数最少，让每个都是 2 度：至少 $8\div2=4$ 个；
④ 答案：至少 $7+4=11$ 个顶点 ✓。
套路：「至少顶点」= 让人均度数尽量大（取最大允许值）。
例 2（判断拓扑序是否合法）. DAG（1→2、1→3、2→4、3→4、4→5），判断下列序列是否为拓扑序：
(a) 1, 2, 3, 4, 5：逐弧检查 1→2 ✓、1→3 ✓、2→4 ✓、3→4 ✓、4→5 ✓ ⇒ 合法；
(b) 1, 3, 2, 4, 5：所有弧依旧「前指后」⇒ 合法（拓扑序不唯一）；
(c) 1, 2, 4, 3, 5：弧 3→4 要求 3 在 4 之前，这里 4 先于 3 ⇒ 非法 ✗。
判法：对每条弧检查两端位置——只要有一条弧「反了」就不是拓扑序。
例 3（关键路径辨析四连）.
(a) 「关键路径是网中的最长路径」⇒ 对（工期定义如此）；
(b) 「关键活动的 l−e=0」⇒ 对（时间余量为零）；
(c) 「一个 AOE 网的关键路径唯一」⇒ 错（可以有多条等长最长路径）；
(d) 「缩短任一关键活动一定能缩短总工期」⇒ 错（可能转移出新的关键路径，总工期取决于新的最长路径）。
方法论：关键路径题的两大陷阱就是「唯一性」与「缩短必有效」。

10决策流程与易错点

图论题
├─ 概念计算
│   ├─ Σdeg=2e；有向 Σ入=Σ出=e
│   ├─ 完全图 n(n−1)/2；非连通最多 (n−1)(n−2)/2
│   └─ 连通最少 n−1 边；强连通有向最少 n 弧
├─ 存储选择
│   ├─ 稠密 / 随机判边 → 邻接矩阵 O(n²)
│   ├─ 稀疏 → 邻接表 O(n+e)（出度易、入度难）
│   ├─ 有向 + 出入度都要 → 十字链表
│   └─ 无向 + 频繁删边 → 邻接多重表
├─ 遍历
│   ├─ BFS：队列分层；无权图最短路
│   └─ DFS：递归深钻；连通性/判环
├─ 四大应用
│   ├─ MST：Prim 稠密 O(n²) / Kruskal 稀疏 O(e log e)
│   ├─ 最短路：Dijkstra 单源非负 O(n²) / Floyd 全源 O(n³)
│   ├─ 拓扑排序：入度 0 出栈；count<n 判环
│   └─ 关键路径：ve 正推 / vl 逆推 / 余量为 0
└─ 收尾：邻接次序是否给定（决定序列唯一性）

易错点清单

  1. 计数口径：无向图 $\sum\deg=2e$；有向图按入、出两个方向分别满足 $\sum\text{入}=\sum\text{出}=e$。
  2. 度与「至少顶点」题：剩余度数按「最大允许度数」平分（如 <3 就按 2），别按 1 算。
  3. 有向图行/列：邻接矩阵行和=出度、列和=入度——写反是最高频错。
  4. 邻接表不唯一：由它推出的 BFS/DFS 序列、生成树也不唯一——题目没给次序时答案可多解。
  5. BFS 求最短路仅限无权图：带权图必须 Dijkstra（BFS 层数≠加权距离）。
  6. 非连通图别忘外层循环：一次 BFS/DFS 只走完一个连通分量；生成的是森林。
  7. Prim 的候选边：必须「一端在集合内、一端在外」——两端都在外的更小边不是候选（§5 Prim 例题的常见坑）。
  8. Kruskal 判环：用并查集（第五章 §8），不是直觉「看一眼」。
  9. Dijkstra 三禁：负权边、负权边、还是负权边（会破坏「选最小即定死」的依据）；Floyd 允许负权但禁负环。
  10. 拓扑排序：存在拓扑序 ⇔ 无环；输出数 < $n$ 判环；每步入度 0 顶点多于一个 ⇒ 序列不唯一。
  11. 关键路径 = 最长路径：不是最短；缩短关键活动可能转移关键路径、总工期未必变。
  12. 复杂度成对记：遍历「矩阵 O(n²) / 表 O(n+e)」；拓扑 $O(n+e)$；MST「Prim $O(n^2)$ / Kruskal $O(e\log e)$」。

主题结论
